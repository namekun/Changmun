*Changmun* (창문) は韓国語で「窓」のことです。ブラウザの名前としては、なかなかの直球です。無料のオープンソースで、アカウントもトラッキングもありません。アプリは英語、韓国語、日本語、簡体字中国語、スペイン語、ドイツ語、フランス語に対応しています。

## なぜChangmunか

- **軽い。** Chromium系のブラウザはそれぞれ自前のChromiumを抱えていますが、ChangmunはmacOSにすでに入っているWebKitエンジン (Safariが使っているもの) を借ります。ダウンロードは約3MB (0.4.1のDMGは2.6MB) で、バッテリーにも優しく、エンジンのセキュリティ修正はmacOSとSafariのアップデートで届きます。
- **ArcやDiaのようなサイドバー。** 縦型タブはタイトルがゆったり読めます。タイル状のお気に入り、ブックマークフォルダ、タブグループ、スペースもあります。
- **ブラウザを使うAI。** Claudeパネルが、すでにお使いの`claude` CLIを通じてページを読み、クリックや入力を代わりに行います。手は貸しても、好き勝手はさせません。リスクのある操作の前には、先に確認します。
- **最初からプライベート。** アカウントもサーバもアナリティクスもないので、登録するものがありません。広告とトラッカーのブロックは内蔵しています。
- **引っ越しは荷物ごと。** SafariとChromium系ブラウザからブックマークと履歴を、Chromium系ブラウザからはパスワードとサインインも読み込めます。ただしSafariのパスワードだけは、macOSがほかのアプリに渡さないので置いていくことになります。

## インストール

```sh
brew install --cask namekun/tap/changmun
```

[Homebrew](https://brew.sh)、macOS 14 Sonoma以降、Appleシリコン搭載のMacが必要です。アプリはDeveloper IDで署名され、Appleの公証を受けているので、すぐに開きます。アップデートは`brew update && brew upgrade --cask changmun`で行います。

初回起動時に、いま使っているブラウザからブックマークと履歴を (Chromium系ならパスワードとログイン状態も) 読み込むかどうかを確認します。

### ソースからビルド

macOS 14以降と、XcodeまたはCommand Line Toolsが必要です。

```sh
git clone https://github.com/namekun/Changmun.git
cd Changmun
scripts/bundle.sh release   # makes build/Changmun.app
open build/Changmun.app
```

Command Line Toolsだけがインストールされている場合、スクリプトはmacOS 26 SDKでビルドします (macOS 27 SDKのSwiftUIマクロプラグインはXcodeにしか含まれていません)。ビルド成果物はiCloudのデスクトップ同期の影響を受けないよう、`~/Library/Caches/Changmun/build`に出力されます。

## 主な機能

### サイドバーとタブ

- **サイドバー。** お気に入り、ブックマーク、開いているタブを左の1列にまとめます。お気に入りはタイル、ブックマークはフォルダ、タブは縦型に並びます。タブはドラッグして並べ替えられ、お気に入りへドラッグすると固定できます。お気に入りとブックマークは、DiaやArcと同様にそれぞれ専用のタブを持ちます。クリックすると、読んでいるタブを置き換えずにそのタブへ移動します (⌘クリックで新規タブに開きます)。ページのリンクをサイドバーへドラッグするとタブとして開き、お気に入りやフォルダにドロップするとそこに保存されます。タブのメニューからは再読み込み、複製、新規ウインドウへの移動、共有、ほかのブラウザで開くこともできます。グループのタブをすべて閉じたりブックマークを削除したりしても、数秒間は取り消せます。後悔先に立たずと言いますが、この数秒間だけは取り消しが間に合います。
- **アドレスバーはお好みの場所に。** 手が覚えている配置を選べます。Arcのようにサイドバー上部の戻る・進むボタンの下、またはDiaのようにページの上に置けます (設定 › 外観 › アドレスバーの位置)。サイト名だけを表示し、盾と星はポインタを置くと現れます。お気に入りのページは星が常に表示され、クリックするとお気に入りから外せます。
- **ブックマークフォルダ。** 整理したままの形で、すぐ手の届くところに置けます。読み込んだフォルダは元のブラウザと同じ入れ子のまま並びます。よく使うフォルダはサイドバーに固定して (右クリックか … › サイドバーに固定、またはお気に入りの下へドラッグ)、その場で開けます。ブックマークは別のフォルダやお気に入りへドラッグするか、メニューの移動で移せます。そのほかのブックマークはサイドバー下部のブックマークボタンから検索付きで開け、隣の … からは履歴、アーカイブしたタブ、集中モード、設定を開けます。
- **タブグループ。** 関連するタブをひとまとめにして、視界の外へ片づけます。タブを右クリック › 新規グループに追加で名前を付けて、折りたたみもできます。グループのタブから開いたタブはそのグループに入り、開き直したタブ (⌘⇧T) は元のグループに戻ります。グループはヘッダーをドラッグして移動でき、お気に入りや固定したフォルダの上へドラッグすると、タブごと一つのブックマークフォルダにまとまります。
- **タブの整理。** ばらばらのタブを、ワンクリックでグループにまとめます。「新規タブ」の横にある魔法の杖 (ウインドウ › タブを整理) をひと振りすると、グループに入っていないタブがまとまります。Apple Intelligenceがオン (macOS 26) なら、Mac上のモデルがトピックごとにグループ化して名前も付けます。タブの情報がMacの外に出ることはありません。オフの場合は、互いに開いたタブと同じサイトのタブをまとめます。「取り消す」を押すと、数秒間は元に戻せます。アドレスバーから開いた新しいタブは、合うグループに自動で入ります (設定 › タブでオフにできます)。
- **古いタブのアーカイブ** (デフォルトではオフ)。しばらく見ていないタブを、捨てずにしまっておきます。設定した時間 (12時間～30日、Changmunの起動中だけを数えます) 見ていないタブは、履歴 › アーカイブしたタブに閉じられ、元のグループへ開き直せます。表示中のタブ、再生中のタブ、ピクチャインピクチャ中のタブ、カメラやマイクを使用中のタブ、お気に入りのタブ、プライベートタブは、アーカイブされません。
- **スリープするタブ。** バックグラウンドのタブにはひと眠りしてもらい、メモリを返してもらいます。バックグラウンドで20分間見ていないタブと、メモリが逼迫したときのすべてのバックグラウンドのタブは、Webプロセスを手放します。戻ると履歴とともに復帰します。
- **コマンドバー** (⌘T)。1つの入力欄で、検索、アドレスの入力、開いているタブ・ブックマーク・履歴への切り替え、AIへの質問まで済ませられます。

### スペースとプロファイル

- **スペース。** 用途に合わせて、タブ、タブグループ、お気に入りを別々にしておけます。仕事のタブが週末までついてくることはありません。サイドバー最下部の行でスペースを切り替えます。ドットをクリックするか、⌃1〜⌃9を押すか、サイドバーの上を2本指で横にスワイプします (ウインドウ › 次のスペース、前のスペース、新しいスペース…)。スペースごとにタブ、タブグループ、お気に入り、固定したフォルダが別々になり、サイドバーにスペースの色がうっすらつきます。ブックマークのライブラリ、履歴、保存したパスワードは共有です。作成時に「ログインとCookieを分ける（プロファイル）」をオンにすると、Cookieとサイトデータも別になり、同じサイトに2つのアカウントで同時にログインできます。あとから変更はできず、プロファイルを削除するとそのCookieとサイトデータも消去されます。最初のスペースは、これまでのデータから作られます。プライベートウインドウにスペースはありません。AIは通常のスペースのタブを (スペース名つきで) 見られますが、プロファイルのスペースのタブは、そのスペースにいる間だけ見られます。

### 読む・見る

- **リーダーモード。** 記事をすっきりした読みやすい文章で読めます。⇧⌘R (Chrome風ショートカットでは⌥⌘R) で、ページの上に表示します。記事らしいページではアドレスバーにボタンが現れます。Escか×、または同じキーで、ページは元のとおりに戻ります。ページ内の小さなスクリプトで処理します。記事の画像はページが読み込むのと同じ場所から読み込まれ、それ以外にダウンロードや送信は行いません。
- **ページの翻訳。** 別の言語のページを、開いたまま読めます。macOSのオンデバイス翻訳でその場で行います (⌥⌘T、macOS 26以降)。リンクやレイアウトはそのままで、テキストがMacの外に出ることはありません。
- **スプリットビュー** (⌥⌘\\)。1ページでは足りないときのために、2つのタブを並べて表示します。
- **集中モード** (⌘⇧F)。ページ以外をすべて隠します。集中できるかどうかは、あなた次第です。
- **リンクのプレビュー。** 今のページを離れずに、リンク先をちらっと見られます。リンクを⇧クリックすると浮かぶカードに開き、⌘↩ でタブとして残せます。
- **ピクチャインピクチャ** (⌃⌘P)。タブを離れても動画を見続けられます。動画を再生中のタブから移動すると自動でオンになります。⌃⌘← / ⌃⌘→ なら、ほかのAppを使っているときでも5秒戻る・進むができ、「タブに戻る」でそのタブが前面に表示されます。

### プライバシーと安全

- **プライベートウインドウ。** 何も残さずに閲覧できます。Cookieとサイトデータをメモリ上だけに保持し、閉じると消去します。履歴にもセッションにもAIにも渡りません。
- **サイトの設定。** サイトごとにChangmunが覚えていることを、1か所で確認して変更できます。アドレスバー左端の鍵マークをクリックすると、そのサイトについてChangmunが覚えていることが小さなパネルにまとまります: 広告ブロック、ズーム、ポップアップ、カメラとマイク、タブをスリープさせてよいか。サイト名を含め、アドレスバーのほかの場所をクリックすると、これまでどおりアドレスを編集できます。
- **パスワード。** 覚えておくのはキーチェーンの仕事です。サインイン後にキーチェーンへ保存され (httpsのみ)、アドレスバーのキーのボタンから入力します。コピーするにはTouch IDまたはMacのパスワードが必要です。
- **ポップアップ。** ページが勝手にウインドウを開くことは許しません。クリックなしで開かれたポップアップはブロックされ、ページのすぐ上に「開く」と「このサイトでは常に許可」が表示されます。

広告とトラッカーのブロックは下の[広告ブロック](#広告ブロック)に、Macに残るものと送信されるものは[プライバシー](#プライバシー)にまとめています。

### 保存とダウンロード

- **ページを保存。** ページをPDFや画像として残せます。ファイル › PDFとして保存… は1枚の長いPDFに、ファイル › ページ全体をキャプチャ… は画面に見えている部分だけでなくページ全体を1枚の画像にして保存します。どちらもタブのメニューにもあり、別の場所を選ばなければ「ダウンロード」フォルダに保存され、プライベートウインドウでも使えます。ページ内の別の領域でスクロールするものや、スクロールで読み込まれる画像は、すべて取り込まれないことがあります。
- **ダウンロード。** 進み具合を確認でき、初めて開くときには安全確認が入ります。進行状況はサイドバーの下部に表示されます。Safariと同じ隔離フラグが付くので、初めて開くときにGatekeeperが確認します。Appやスクリプト、インストーラは実行せず、Finderで表示します。途中で切れたダウンロードは、その行の「再試行」で止まったところから再開できます。
- **ページの拡大率。** 一度合わせれば、そのサイトではそのまま保たれます。拡大率はサイトごとに記憶されるので、目を細めるのは最初の一回だけです。
- **セッションの保存。** ブラウザも、落ちるときは落ちます。開いているタブは15秒ごとに保存されるので、クラッシュしてもほとんど何も失われません。

### アップデート

- **アップデートのお知らせ。** 新しいバージョンが出るとお知らせします。ChangmunはHomebrewで更新します。1日に1回GitHubで最新リリースを確認し、新しいバージョンがあるとサイドバーの下に控えめなお知らせが出て、`brew upgrade --cask changmun`をコピーできます。設定 › 詳細 › アップデートを確認でオフにできます。

## AI

右側のパネル (⌘E) は、すでにお使いの`claude` CLIを利用するので、Claude Codeのサブスクリプションで動作します。デフォルトのモデルはSonnetで、`defaults write io.github.namekun.Changmun aiModel opus`で切り替えられます。

AIは次のツールでブラウザを操作します: `list_tabs`、`open_tab`、`switch_tab`、`close_tab`、`navigate`、`go_back`、`go_forward`、`reload`、`read_page`、`read_tabs`、`click`、`click_at`、`type_text`、`press_key`、`select_option`、`hover`、`drag`、`wait_for`、`scroll`、`screenshot`。パスワード、ワンタイムコード、カード番号の欄は、値の読み取りも入力もキー操作もできず、スクリーンショットでも隠されます。ファイルのアップロードもできません。

複数のタブにまたがる作業は、チャットの下の「タブを追加」でタブを加えます (1つずつ、タブグループごと、開いているタブすべて)。加えたタブは外せるチップとして表示され、AIは `read_tabs` でまとめて読み、読む前に確認は入りません。2つ以上加えると、パネルがタブの比較や、タブごとの要点のまとめを提案します。

ページに仕込まれた指示によって、読み取った内容がほかの場所へ持ち出されることがないよう、Changmunは次の場合にまず確認します (90秒間応答がなければ拒否として扱います)。

- 表示していないタブを使うとき (タブとサイトごとに1回)。
- アドレスを開くとき。ただし、検索、すでに開いているアドレス、訪問済みまたはブックマーク済みのアドレス、既知のサイトのトップページは除きます。
- チャットがほかのサイトを読み取った後の、クリック、キー操作、ポインタの移動、ドラッグ、テキスト入力、選択肢の選択のたび。何をするかも表示されます。1回だけ許可するか、そのサイトでチャットが終わるまで許可できます。スクロールだけは確認しません。新規チャット (⌘⇧E) では最初からやり直しになります。
- 支払い、注文、送信、投稿、削除など取り消せなさそうな操作は、何を許可していても毎回。

Claude Codeなどのほかのエージェントも、MCP経由で同じツールを同じ確認つきで使えます。

```sh
claude mcp add changmun -- /Applications/Changmun.app/Contents/MacOS/Changmun --mcp
```

`--mcp`を付けると、Changmunが起動していない場合は起動します。制御サーバは127.0.0.1だけで待ち受け、起動のたびに変わるトークンが必要です。

コマンドを実行できるエージェントなら、シェルからも使えます (Homebrewが`changmun`をPATHに置きます)。

```sh
changmun tabs
changmun open example.com
changmun read
changmun read-tabs 3 5
changmun click 12
changmun type 3 "hello" --submit
```

ほかのコマンドは`changmun help`で確認できます。各コマンドは同じツールを1つずつ呼び出し、同じ確認を経て、必要ならChangmunを起動します。

## 広告ブロック

ChangmunはEasyList (広告) とEasyPrivacy (トラッカー) をWebKitのコンテンツブロックルールに変換し、4日ごとに更新します。設定 › プライバシーでは、リストをオフにしたり、アドレスで別のリストを追加したりできます (韓国の広告リストはワンクリックで追加できます)。サイトが正しく表示されないときは、アドレスバーのシールドボタンでそのサイトだけブロックをオフにできます。WebKitで表現できないルール (正規表現、`$redirect`、スクリプトレット、`:has-text`などの拡張セレクタ) は、推測で扱わずにスキップします。広告を1つ見逃すほうが、ページが壊れるよりましだからです。

## 機能拡張

設定 › 機能拡張で管理します (Web機能拡張にはmacOS 15.4以降が必要です)。

プロファイルのスペースのタブでも機能拡張は動作しますが、機能拡張のCookie APIが見られるのは標準のデータストアだけで、プロファイルのものは見えません。

- **App StoreのSafari機能拡張**は、インストールすると一覧に表示され、オンにするときに必要な許可を求めます。
- **Chrome ウェブストアの機能拡張**: 機能拡張のストアページを開くと、ページの上に「Changmunに追加」が表示されます (または設定にアドレスかIDを貼り付けます)。Changmunは`~/Library/Application Support/Changmun/Extensions`に展開し、WebKit機能拡張として読み込みます。もう一度追加すると更新されます。
- **Safariコンテンツブロッカ** (UnicornやAdGuardなど): macOSではブロッカにルールを問い合わせられるのがSafariだけなので、Changmunはブロッカが保存したルールファイルを読み込みます。ほかのアプリケーションのデータの読み込みを許可するか、macOSが一度だけ確認します。
- 展開済みの機能拡張フォルダ (`manifest.json`を含むもの) も読み込めます。ネイティブAppとの通信など、一部の機能は動作しない場合があります。

## ほかのブラウザから読み込む

初回起動時またはメニューから、Safariと、Chrome、Arc (サイドバーを含む)、Dia、Aside、Whale、Brave、Edge、VivaldiといったChromium系ブラウザのブックマークと履歴を読み込めます。Chromium系ブラウザからはパスワードとCookieも読み込むので、ログインしたままの状態を保てます。

- パスワードとCookieは各ブラウザのキーチェーン項目 (`<name> Safe Storage`) で復号するため、macOSが許可を求めます。読み込んだパスワードは、`Changmun`というラベルでログインキーチェーンに保存されます。
- Safariの読み込みにはフルディスクアクセスが必要です。macOSは、Safariのパスワードをほかのアプリケーションに渡しません。

## プライバシー

- 閲覧データはMacの外に出ません。Changmunにはアカウントも、サーバも、アナリティクスもありません。
- アップデートの確認は、1日に1回GitHubの公開リリースAPIから最新のバージョン番号を取得するだけで、ほかには何も送りません (設定 › 詳細でオフにできます)。
- 検索候補を表示すると、コマンドバーに入力した文字が検索エンジンに送信されます (設定でオフにできます。プライベートウインドウからは送信されません)。
- AIパネルは、メッセージと、AIが読み取ったページの内容を、`claude` CLIを通じてAnthropicに送信します。タブの整理とページの翻訳はMac上で実行されます。

## 開発者向け

```sh
scripts/test.sh            # unit tests (Swift Testing)
scripts/check-strings.sh   # every string the code uses is translated in every language
swift scripts/make-icon.swift
scripts/release.sh 0.2.0 notes.md   # checks, DMG, GitHub release, Homebrew tap
```

UIのテキストはコード内では英語で、`Resources/<language>.lproj/Localizable.strings`で翻訳されます。新しい文字列は6つの表すべてに追加してください。

`scripts/headless.sh`は、テストやエージェント向けにヘッドレスのChangmunを実行します。画面の外で動作し、フォーカスを奪わず、音も鳴らさず、`~/Library/Application Support/Changmun Headless`に専用のプロファイルを持ちます。キーチェーンには触れず、AIの確認、サイトの権限、JavaScriptのダイアログには自動で応答します (権限は拒否されます)。

```sh
scripts/headless.sh start                                   # copy build/Changmun.app as the headless app and start it
scripts/headless.sh call open_tab '{"url": "example.com"}'  # the AI's tools: list_tabs, navigate, read_page, click…
scripts/headless.sh shot window.png                         # the whole window, sidebar included
scripts/headless.sh stop
```
