창문(*Changmun*)은 우리말로 *window*예요. 브라우저 이름으로 이만큼 정직한 말도 없죠. 무료 오픈 소스이고, 계정도 추적도 없어요. 앱은 영어, 한국어, 일본어, 중국어 간체, 스페인어, 독일어, 프랑스어를 지원해요.

## 왜 Changmun인가

- **가벼워요.** Chromium을 통째로 싣고 다니지 않아요. macOS에 이미 들어 있는 WebKit(Safari가 쓰는 엔진)을 빌려 써서 내려받는 크기가 약 3MB예요(0.4.1 DMG는 2.6MB). 배터리도 덜 쓰고, 엔진 보안 수정은 macOS와 Safari 업데이트로 들어와요.
- **Arc·Dia 같은 사이드바.** 세로 탭은 제목이 들어갈 자리가 넉넉해요. 타일 즐겨찾기, 북마크 폴더, 탭 그룹, 스페이스도 있고요.
- **브라우저를 쓰는 AI.** Claude 패널이 이미 설치한 `claude` CLI로 페이지를 읽고 대신 클릭하고 입력해요. 손은 빌려주되 알아서 하게 두지는 않아서, 위험한 동작 앞에서는 먼저 물어봐요.
- **비공개가 기본이에요.** 계정도 서버도 분석 도구도 없고, 광고·추적 차단이 기본으로 들어 있어요.
- **이삿짐은 알아서 옮겨요.** Safari와 Chromium 계열 브라우저의 북마크와 방문 기록을 가져오고, Chromium 계열에서는 비밀번호와 로그인도 가져와요. 다만 Safari 비밀번호는 macOS가 내주지 않아서 놓고 와야 해요.

## 설치

```sh
brew install --cask namekun/tap/changmun
```

[Homebrew](https://brew.sh)가 필요하고, macOS 14 Sonoma 이상의 Apple 실리콘 Mac에서 돌아가요. 앱은 Developer ID로 서명하고 Apple 공증까지 받아서 바로 열려요. 업데이트는 앱 안에서 받아요(Changmun › 업데이트 확인…, 기본은 자동). Homebrew는 설치할 때만 쓰면 돼요.

처음 실행하면 지금 쓰는 브라우저의 북마크와 방문 기록을, Chromium 계열이면 비밀번호와 로그인 상태까지 가져올지 물어봐요.

### 소스에서 빌드

macOS 14 이상과 Xcode 또는 Command Line Tools가 필요해요.

```sh
git clone https://github.com/namekun/Changmun.git
cd Changmun
scripts/bundle.sh release   # makes build/Changmun.app
open build/Changmun.app
```

Command Line Tools만 깔려 있으면 스크립트가 macOS 26 SDK로 빌드해요(macOS 27 SDK의 SwiftUI 매크로 플러그인은 Xcode에만 들어 있어요). 빌드 결과물은 iCloud 데스크탑 동기화에 걸리지 않게 `~/Library/Caches/Changmun/build`에 둬요.

## 하는 일

### 사이드바와 탭

- **사이드바.** 즐겨찾기, 북마크, 열린 탭이 왼쪽 한 줄에 모여 있어요. 즐겨찾기는 타일로, 북마크는 폴더로, 탭은 세로로 쌓여요. 탭은 끌어서 순서를 바꾸고, 즐겨찾기 위로 끌면 고정돼요. 즐겨찾기와 북마크는 Dia·Arc처럼 저마다 자기 탭이 따로 있어서, 누르면 보던 탭을 덮어쓰지 않고 그 탭으로 가요(⌘-클릭은 새 탭). 페이지의 링크를 사이드바로 끌어다 놓으면 탭으로 열리고, 즐겨찾기나 폴더에 놓으면 바로 저장돼요. 탭 메뉴에는 새로고침, 복제, 새 창으로 옮기기, 공유, 다른 브라우저로 열기도 있어요. 그룹의 탭을 모두 닫거나 북마크를 지워도 몇 초 안에는 되돌릴 수 있어요. 후회는 보통 그 안에 찾아오니까요.
- **주소창 위치.** 손에 익은 배치를 골라요. Arc처럼 사이드바 맨 위 뒤로·앞으로 버튼 아래에 두거나, Dia처럼 페이지 위에 둘 수 있어요(설정 › 모양 › 주소창 위치). 사이트 이름만 보이고, 방패와 별은 포인터를 올리면 나와요. 즐겨찾기에 있는 페이지는 별이 늘 보이고, 별을 누르면 즐겨찾기에서 빠져요.
- **북마크 폴더.** 정리해 둔 모습 그대로, 손 닿는 곳에 둬요. 가져온 폴더는 원래 브라우저처럼 폴더 안에 폴더로 들어가요. 자주 쓰는 폴더는 사이드바에 고정해 두고(우클릭이나 … › 사이드바에 고정, 또는 즐겨찾기 아래로 끌어 올리기) 바로 거기서 펼쳐 써요. 북마크는 다른 폴더나 즐겨찾기로 끌어다 놓거나 메뉴의 옮기기로 옮기고요. 나머지 북마크는 사이드바 맨 아래 북마크 버튼에 검색칸과 함께 있어요. 그 옆 … 버튼에서는 방문 기록, 보관한 탭, 집중 모드, 설정을 열어요.
- **탭 그룹.** 관련 있는 탭끼리 묶어서 눈에 덜 띄게 해요. 탭 우클릭 › 새 그룹으로 묶기를 고르고 이름을 붙인 뒤 접어 두면 돼요. 그룹의 탭에서 새로 연 탭은 같은 그룹에 들어가고, 닫았다 다시 연 탭(⌘⇧T)은 원래 그룹으로 돌아가요. 그룹은 머리글을 끌어서 옮기고, 즐겨찾기나 고정한 폴더 쪽으로 끌어 올리면 탭째로 북마크 폴더 하나에 담겨요.
- **탭 정리.** 마술봉 한 번이면 흩어진 탭이 그룹으로 모여요. 새 탭 옆의 마술봉 버튼(윈도우 › 탭 정리)이 그룹에 없는 탭을 묶어 줘요. Apple Intelligence가 켜져 있으면(macOS 26) 이 Mac 안의 모델이 주제별로 묶고 이름까지 붙여요. 탭 정보는 Mac 밖으로 나가지 않아요. 쓸 수 없을 때는 한 탭에서 열어 간 탭끼리, 같은 사이트 탭끼리 묶고요. 정리한 뒤 몇 초 동안은 실행 취소로 되돌릴 수 있어요. 주소창에서 새로 연 탭은 맞는 그룹에 저절로 들어가요(설정 › 탭에서 끌 수 있어요).
- **오래 안 본 탭 보관**(기본은 끔). 한동안 안 본 탭을 지우지 않고 치워 둬요. Changmun이 켜져 있는 동안 정한 시간(12시간~30일) 넘게 보지 않은 탭은 닫혀서 방문 기록 › 보관한 탭에 모이고, 원래 그룹으로 다시 열 수 있어요. 화면에 보이는 탭, 재생 중인 탭, 화면 속 화면 탭, 카메라·마이크를 쓰는 탭, 즐겨찾기 탭, 개인 창의 탭은 보관하지 않아요.
- **탭 재우기.** 백그라운드 탭을 재워서 메모리를 아껴요. 20분 넘게 안 본 백그라운드 탭은 잠깐 재워요. 메모리가 모자랄 때는 백그라운드 탭을 전부 재우고요. 잠든 탭은 웹 프로세스를 내려놓고, 다시 누르면 방문 기록까지 그대로 아무 일 없었다는 듯 돌아와요.
- **명령 막대**(⌘T). 검색, 주소 입력, 열린 탭으로 전환, 북마크·방문 기록 찾기, AI에게 질문까지 한 칸에서 해결해요.

### 스페이스와 프로필

- **스페이스.** 용도별로 탭, 탭 그룹, 즐겨찾기를 따로 나눠 둬요. 일하던 탭이 주말까지 따라오지 않아요. 사이드바 맨 아래 줄에서 스페이스를 오가요. 점을 누르거나 ⌃1–⌃9를 누르거나, 사이드바 위에서 두 손가락으로 옆으로 쓸어 넘기면 돼요(윈도우 › 다음 스페이스, 이전 스페이스, 새 스페이스…). 스페이스마다 탭, 탭 그룹, 즐겨찾기, 고정한 폴더가 따로 있고, 사이드바에는 그 스페이스의 색이 은은하게 입혀져요. 북마크 보관함, 방문 기록, 저장된 비밀번호는 함께 써요. 만들 때 "로그인·쿠키 따로 쓰기 (프로필)"를 켜면 쿠키와 사이트 데이터도 따로 보관해서, 같은 사이트에 계정 두 개로 나란히 로그인할 수 있어요. 나중에 바꿀 수 없고, 프로필을 지우면 그 쿠키와 사이트 데이터도 같이 지워져요. 첫 스페이스는 원래 쓰던 데이터로 만들어져요. 개인 창에는 스페이스가 없어요. AI는 일반 스페이스의 탭은 (스페이스 이름과 함께) 볼 수 있지만, 프로필 스페이스의 탭은 그 스페이스에 있는 동안에만 볼 수 있어요.

### 읽기와 보기

- **읽기 모드.** 기사에서 군더더기를 걷어 내고 글만 보여 줘요. ⇧⌘R(Chrome 방식 단축키에서는 ⌥⌘R)을 누르면 페이지 위에 읽기 화면이 덮여요. 기사로 보이는 페이지에서는 주소창에 버튼이 나타나요. Esc나 ×, 또는 같은 단축키를 누르면 페이지가 그대로 돌아와요. 페이지 안에서 작은 스크립트가 처리하고, 기사 속 이미지는 페이지가 원래 불러오던 곳에서 그대로 불러와요. 그 밖에 내려받거나 보내는 건 없어요.
- **페이지 번역.** 다른 언어로 된 페이지를 떠나지 않고 읽어요. macOS의 온디바이스 번역으로 그 자리에서 바꿔 주고(⌥⌘T, macOS 26 이상), 링크와 배치는 그대로예요. 글은 Mac 밖으로 나가지 않아요.
- **분할 보기**(⌥⌘\\). 창을 둘로 나누지 않아도 탭 두 개를 나란히 볼 수 있어요.
- **집중 모드**(⌘⇧F). 페이지만 남기고 모두 숨겨요. 집중하는 건 본인 몫이고요.
- **링크 미리보기.** 보던 페이지를 떠나지 않고 링크를 슬쩍 봐요. 링크를 ⇧-클릭하면 떠 있는 카드로 열리고, ⌘↩를 누르면 탭으로 남아요.
- **화면 속 화면**(⌃⌘P). 탭을 떠나도 영상은 계속 볼 수 있어요. 영상이 재생 중인 탭에서 다른 탭으로 가면 저절로 켜져요. ⌃⌘← / ⌃⌘→로 5초씩 건너뛰는 건 다른 앱을 쓰는 중에도 되고, "탭으로 돌아가기"를 누르면 그 탭이 앞으로 나와요.

### 개인정보와 안전

- **개인 창.** 흔적을 남기지 않고 둘러봐요. 쿠키와 사이트 데이터는 메모리에만 두었다가 창을 닫으면 지워요. 방문 기록, 세션, AI로는 아무것도 넘어가지 않아요.
- **사이트 설정.** 사이트마다 Changmun이 기억하는 것을 한곳에서 보고 바꿔요. 주소창 왼쪽의 자물쇠 아이콘을 누르면 그 사이트용으로 기억해 둔 항목이 작은 창에 모여 나와요. 광고 차단, 확대/축소, 팝업, 카메라·마이크, 탭을 재워도 되는지까지요. 사이트 이름을 포함해 주소창의 다른 곳을 누르면 전처럼 주소를 고칠 수 있어요.
- **비밀번호.** 외우는 건 키체인 몫이에요. 로그인하고 나면 키체인에 저장되고(https만), 주소창의 열쇠로 채워요. 복사하거나 채울 때 Touch ID나 Mac 암호로 확인해요(채울 때 확인은 설정 › 개인정보에서 끌 수 있어요).
- **팝업.** 페이지가 멋대로 창을 열지 못하게 해요. 클릭 없이 열리는 팝업은 막고, 페이지 바로 위에 "열기"와 "이 사이트는 항상 허용"을 띄워요.

광고·추적 차단은 아래 [광고 차단](#광고-차단)에, 무엇이 Mac에 남고 무엇이 전송되는지는 [개인정보](#개인정보)에 있어요.

### 저장과 다운로드

- **페이지 저장.** 페이지를 PDF나 그림으로 남겨 둬요. 파일 › PDF로 저장…은 한 장짜리 긴 PDF로, 파일 › 전체 페이지 캡처…는 화면에 보이는 부분이 아니라 페이지 전체를 그림 한 장으로 저장해요. 둘 다 탭 메뉴에도 있고, 따로 고르지 않으면 다운로드 폴더에 저장되며 개인 창에서도 써요. 안쪽 패널 안에서 스크롤되는 페이지나 스크롤해야 불러오는 이미지는 다 담기지 않을 수 있어요.
- **다운로드.** 내려받는 상황을 보여 주고, 처음 열 때는 안전 검사를 거쳐요. 진행률은 사이드바 아래에 보여요. 받은 파일에는 Safari처럼 격리 표시가 붙어서 처음 열 때 Gatekeeper가 검사해요. 앱·스크립트·설치 패키지는 실행하지 않고 Finder에서 보여 줘요. 받다가 끊긴 다운로드는 그 행의 다시 시도를 누르면 멈춘 곳부터 이어 받아요.
- **페이지 확대.** 한 번 키워 두면 그 사이트에서는 계속 그 크기예요. 확대 비율을 사이트별로 기억하거든요.
- **세션 저장.** 브라우저도 가끔 죽어요. 열린 탭을 15초마다 저장하니 비정상 종료돼도 거의 잃는 게 없어요.

### 업데이트

- **자동 업데이트.** Changmun이 Sparkle로 스스로 업데이트해요. 하루에 한 번 백그라운드에서 확인하고, 새 버전이 나오면 설치할지 물어봐요. Changmun › 업데이트 확인…을 고르면 바로 확인해요. 업데이트에는 서명이 있어서, 앱에 들어 있는 키와 맞는 것만 설치해요. 설정 › 고급에서 자동 확인을 끄거나, 알아서 내려받아 설치하게 할 수 있어요.

## AI

오른쪽 패널(⌘E)은 이미 설치된 `claude` CLI를 쓰니 Claude Code 구독으로 돌아가요. 기본 모델은 Sonnet이고, `defaults write io.github.namekun.Changmun aiModel opus`로 바꿀 수 있어요.

AI는 이 도구들로 브라우저를 다뤄요: `list_tabs`, `open_tab`, `switch_tab`, `close_tab`, `navigate`, `go_back`, `go_forward`, `reload`, `read_page`, `read_tabs`, `click`, `click_at`, `type_text`, `press_key`, `select_option`, `hover`, `drag`, `wait_for`, `scroll`, `screenshot`, `sign_in`. 비밀번호·인증 코드·카드 칸은 읽지도, 입력하거나 키를 누르지도 못하고, 스크린샷에서도 가려져요. 파일 업로드도 못 해요.

- `read_page`는 요소마다 상태를 대괄호로 붙여요: `[checked]`·`[unchecked]`, `[selected]`, `[expanded]`·`[collapsed]`, `[disabled]`, `[focused]`, `[pressed]`, `[required]`, `[invalid]`. 칸과 목록의 현재 값도 한 줄로 보여 주지만, 비밀번호·코드·카드 칸은 값을 절대 보여 주지 않아요.
- `click`, `click_at`, `type_text`, `press_key`, `select_option`, `hover`, `drag`가 끝나고 페이지가 가라앉으면(최대 1.5초쯤), 마지막으로 본 뒤 바뀐 것을 돌려줘요. 주소·제목이 바뀌었는지, 새로 생긴(`+`, 번호가 새로 붙어 바로 쓸 수 있어요)·바뀐(`~`)·사라진(`-`) 요소를요. 최대 40줄이고, 페이지가 이동했으면 그렇다고만 알리고 `read_page`를 권해요. 읽은 것과 똑같이 기록해요. 포커스만 바뀐 것은 맨 끝에 알리고 40줄에 세지 않아요. 응답하지 않는 프레임은 건너뛰고 그렇다고 알려요. 사라졌다가 다시 나타난 요소(다시 연 메뉴)는 다시 새 요소로 알려요.
- `screenshot`에 `labels`를 주면 페이지를 다시 읽어서, 보이는 요소마다 `read_page`와 같은 번호를 그림 위에 박스로 그려 줘요. 페이지에는 아무것도 넣지 않고 그림에만 그려요. 박스 위치는 페이지의 레이아웃을 따르니, 요소에 대해서는 `read_page`가 기준이에요. `changmun screenshot --labels`도 돼요.
- 모든 도구는 선택 인자 `title`(예: "가격 비교하는 중")을 받아요. 패널의 진행 줄에 그대로 보이고, 없으면 Changmun이 만든 문구가 나와요. 모델이 쓴 글이라 한 줄, 60자까지로 다듬고, 확인 창이나 판단에는 쓰지 않아요. 제목은 Changmun이 만든 문구 뒤에 붙고("‘구매’ 클릭 중 · 가격 비교하는 중") 문구를 대신하지 않아요. `sign_in`과 매번 묻는 동작에는 Changmun의 문구만 보여요.
- AI가 일하는 중에도 입력창에 보낼 수 있어요. Return은 메시지를 칩으로 대기시켜 두었다가 이번 실행이 잘 끝나면 순서대로 보내요(쓴 순간의 탭과 함께). 실행이 실패하거나 중단되면 "대기열 보내기" 버튼이 기다려요. ⌘Return은 지금 실행을 멈추고(정지와 똑같이) 같은 대화에서 새 메시지로 바로 이어 가요. 정지와 새 대화는 대기열을 비워요. 대기열은 8개까지고 넘치면 알려 줘요. 기다리는 동안 두 번째 ⌘Return은 첫 번째에 이어 붙어요. 중단한 뒤 대화를 이어갈 수 없으면 새 대화로 다시 보내고 패널에 알려요. 입력기(한국어·일본어·중국어)로 글자를 조합하는 중에는 Return이 입력기의 것이라 보내지 않아요.
- `sign_in`은 저장된 로그인을 AI가 보지 못하게 양식에 채워 줘요. 페이지의 정확한 호스트가 저장된 로그인의 호스트와 같아야 하고(https만), 시크릿 창에서는 쓸 수 없어요. 매번 "AI가 ○○에 △△ 계정으로 로그인하게 할까요?"라고 묻고(계정이 여러 개면 창에서 직접 골라요) Touch ID나 Mac 암호로 확인해요. 저장된 로그인이 없거나 거부·무응답·인증 실패일 때 AI는 똑같이 "로그인하지 못했어요"라는 말만 들어서, 어떤 계정이 있는지 알아낼 수 없어요. AI는 비밀번호도 계정 이름도 받지 못해요. 버튼은 누르지 않아요. 그다음 클릭은 AI가 하고, 다른 클릭과 똑같이 확인해요. 저장된 로그인이 없어도 닫기만 되는 창이 뜨고 AI는 똑같이 기다려요. 거부한 사이트는 같은 대화에서 창 없이 4초를 기다린 뒤 패널에 알려요. 양식이나 전송 버튼(어디 있든)이 다른 사이트로 보내면 거부해요.

여러 탭에 걸친 일은 채팅 아래의 "탭 추가"로 탭을 붙이면 돼요(하나씩, 탭 그룹째, 열린 탭 전부). 붙인 탭은 칩으로 나타나고 하나씩 뺄 수 있어요. AI는 `read_tabs`로 이 탭들을 한꺼번에 읽고, 읽기 전에 따로 묻지는 않아요. 두 개 이상 붙이면 패널이 탭 비교하기와 탭마다 핵심만 정리하기를 제안해요.

페이지에 몰래 숨겨 둔 "읽은 걸 저기로 보내" 같은 지시에 AI가 넘어가지 않도록, Changmun이 위험한 순간마다 확인 창으로 먼저 물어봐요. 90초 동안 답이 없으면 거부로 처리해요.

- 보고 있지 않은 탭을 쓰기 전에, 탭과 사이트마다 한 번 물어봐요.
- 주소를 열기 전에 물어봐요. 검색, 이미 열려 있거나 방문·북마크한 주소, 아는 사이트의 첫 화면은 예외예요.
- 대화에서 다른 사이트를 읽은 뒤에는 클릭, 키 입력, 가리키기, 드래그, 텍스트 입력, 옵션 선택을 할 때마다 물어봐요. 무엇을 하려는지 미리 보여 주고, 한 번만 허용하거나 대화가 끝날 때까지 그 사이트에서 허용할 수 있어요. 스크롤, 앞에 있는 페이지 보기(읽기, 스크린샷, 기다리기, 탭 목록), 뒤로·앞으로·새로고침은 묻지 않아요. 새 대화(⌘⇧E)를 열면 처음부터 다시 시작해요.
- 결제, 주문, 전송, 게시, 댓글, 공유, 업로드, 접근 허용(허용·연결·승인), 삭제, 취소, 탈퇴처럼 되돌릴 수 없거나 내주는 동작은 무엇을 허용했든 매번 물어봐요(한 번만 허용하거나 허용 안 함). 메시지 입력창의 Enter, 다른 사이트로 보내는 양식, 텍스트 칸 밖의 Delete·Backspace도 같아요.
- 쿠키 배너의 수락·허용·동의와 저장, 지우기, 초기화, 차단 같은 설정은 사이트마다 한 번 물어봐요. AI 패널에서는 대화가 끝날 때까지, MCP 에이전트는 그 연결이 이어지는 동안(그 Claude Code 세션의 MCP 서버가 끝날 때까지) 그 사이트에서 허용할 수 있어요. 명령줄은 매번 물어봐요.

Claude Code 같은 다른 에이전트도 MCP로 같은 도구를 쓸 수 있어요. 확인 절차도 똑같고요.

```sh
claude mcp add changmun -- /Applications/Changmun.app/Contents/MacOS/Changmun --mcp
```

앱이 꺼져 있으면 `--mcp`가 Changmun을 먼저 띄워요. 제어 서버는 127.0.0.1에서만 열리고, 실행할 때마다 바뀌는 토큰이 있어야 해요.

셸에서도 쓸 수 있어요. 명령을 실행할 수 있는 에이전트라면 무엇이든 괜찮아요(Homebrew가 `changmun`을 PATH에 넣어 줘요).

```sh
changmun tabs
changmun open example.com
changmun read
changmun read-tabs 3 5
changmun click 12
changmun type 3 "hello" --submit
```

나머지 명령은 `changmun help`에 있어요. 명령 하나가 도구 하나에 대응하고, 확인 절차도 똑같고, 필요하면 Changmun을 먼저 띄워요.

### 에이전트용 화면 없는 Changmun

지금 쓰는 브라우저에서 에이전트가 계속 물어보면 금방 지쳐요. 그래서 창 없는 Changmun을 하나 더 뒀어요. 눈에 보이지 않고, 포커스를 가져가지도 소리를 내지도 않아요. 프로필도 따로라서 내 쿠키, 방문 기록, 비밀번호, 키체인은 하나도 없어요.

```sh
changmun headless start     # 명령을 실행한 앱을 ~/Library/Application Support/Changmun Agent에 복사해 띄워요
changmun headless status    # 실행 중인지, pid, 버전, 프로필 폴더
changmun --headless open example.com
changmun --headless read
changmun headless stop
claude mcp add changmun-headless -- /Applications/Changmun.app/Contents/MacOS/Changmun --mcp --headless
```

아무 명령에나 `--headless`를 붙이면 지금 쓰는 브라우저 대신 이쪽으로 가요. MCP는 `--mcp --headless`고요. 꺼져 있으면 둘 다 먼저 띄워요. 여기서는 AI가 다른 탭을 쓰거나, 새 주소를 열거나, 다른 사이트를 읽은 뒤 행동하기 전에 묻지 않아요. 페이지에 숨은 지시를 막으려고 평소에는 묻던 질문을 꺼 둔 거예요. 그래서 빈 프로필의 별도 복사본으로 두고, 되돌릴 수 없는 일은 거절해요. 결제, 주문, 전송, 게시, 삭제, 접근 허용처럼 보이는 동작과, 페이지가 쿠키 배너라고 우기기만 하는 영역 안의 동작은 "사람이 필요하다"는 오류가 가요. 지켜보는 사람이 없고, 그 안에서 로그인한 사이트는 AI가 마음대로 쓸 수 있으니까요. 나머지는 모두 허용해요. 사이트 권한(카메라, 위치 등)은 거부하고요. 복사본은 명령을 실행한 앱으로 만들고, 그 앱의 버전이 바뀌면 다시 만들어요(`changmun headless status`가 알려 줘요). 스스로 업데이트하지는 않아요.

## 광고 차단

EasyList(광고)와 EasyPrivacy(추적)를 WebKit 콘텐츠 차단 규칙으로 바꿔 쓰고, 4일마다 새로 받아요. 설정 › 개인정보에서 목록을 끄거나 다른 목록을 주소로 더할 수 있어요(한국 광고 목록은 한 번에 추가돼요). 사이트가 깨지면 주소창의 방패 버튼으로 그 사이트만 꺼요. WebKit이 표현하지 못하는 규칙(정규식, `$redirect`, 스크립틀릿, `:has-text` 같은 확장 선택자)은 잘못 막느니 건너뛰어요. 광고 하나 놓치는 게 페이지가 깨지는 것보다 나으니까요.

## 확장 프로그램

설정 › 확장에서 관리해요(웹 확장은 macOS 15.4 이상).

프로필 스페이스의 탭에서도 확장 프로그램은 동작하지만, 확장 프로그램의 쿠키 API는 기본 데이터 저장소만 보고 프로필의 것은 보지 못해요.

- **App Store의 Safari 확장**: 설치하면 목록에 저절로 나타나고, 켤 때 권한을 물어봐요.
- **Chrome 웹 스토어 확장**: 스토어의 확장 페이지를 열면 페이지 위에 "Changmun에 추가"가 떠요(설정에 주소나 ID를 넣어도 돼요). 받은 확장은 `~/Library/Application Support/Changmun/Extensions`에 풀어 두고 WebKit 확장으로 불러와요. 다시 추가하면 업데이트돼요.
- **Safari 콘텐츠 차단기**(Unicorn, AdGuard 등): macOS는 Safari만 차단기에 규칙을 요청할 수 있게 해 둬서, Changmun은 차단기가 저장해 둔 규칙 파일을 읽어서 적용해요. 처음 켤 때 macOS가 다른 앱의 데이터를 읽어도 되는지 한 번 물어봐요.
- 압축을 푼 확장 폴더(`manifest.json`이 든 폴더)도 불러올 수 있어요. 네이티브 앱과 주고받는 기능처럼 일부는 동작하지 않을 수 있어요.

## 다른 브라우저에서 가져오기

첫 실행 때나 메뉴에서 Safari와 크로미움 계열(Chrome, Arc(사이드바 포함), Dia, Aside, Whale, Brave, Edge, Vivaldi)의 북마크와 방문 기록을 가져와요. 크로미움 계열에서는 비밀번호와 쿠키도 가져와서 로그인 상태가 그대로 유지돼요.

- 비밀번호와 쿠키는 각 브라우저의 키체인 항목(`<이름> Safe Storage`)으로 복호화하기 때문에 macOS 허용 창이 떠요. 가져온 비밀번호는 로그인 키체인에 `Changmun`이라는 이름표로 저장돼요.
- Safari는 전체 디스크 접근 권한이 있어야 읽을 수 있어요. Safari 비밀번호는 macOS가 다른 앱에 내주지 않아요.

## 개인정보

- 웹에서 한 일은 이 Mac 안에만 남아요. Changmun에는 계정도 서버도 분석 도구도 없어요.
- 업데이트 확인은 GitHub Pages에서 작은 릴리스 목록(`appcast.xml`)을 받아 와요. GitHub는 일반 웹 서버처럼 요청을 받으니 Changmun의 이름과 버전은 볼 수 있어요. Mac에 관한 정보를 더하는 Sparkle의 시스템 프로필은 꺼져 있고 계속 꺼 둬요(설정 › 고급에서 확인 자체를 끌 수 있어요).
- 검색어 추천은 명령 막대에 입력한 글자를 검색 엔진에 보내요(설정에서 끌 수 있고, 개인 창에서는 보내지 않아요).
- AI 패널은 `claude` CLI를 거쳐 입력한 메시지와 AI가 읽은 페이지 내용을 Anthropic에 보내요. 탭 정리와 페이지 번역은 이 Mac 안에서 돌아요.

## 비밀번호와 보안

비밀번호를 동기화하는 브라우저에는 이런 질문이 따라붙어요. 내 비밀번호의 암호화된 사본이 회사 서버에 있다면, 회사가 그걸 풀어서 내 계정에 로그인하거나, 회사가 망할 때 팔아넘길 수 있지 않느냐는 거예요. Changmun의 답은 짧아요. 아래 내용은 모두 코드에서 확인했어요.

- **어디에 있나요.** 이 Mac의 로그인 키체인에 `Changmun`이라는 이름표가 붙은 인터넷 암호로 저장돼요(키체인 접근에서 검색해 보세요). 동기화 가능 항목으로 표시하지 않으니 iCloud 키체인도 어디로 가져가지 않아요. 설정 › 개인정보 › 저장된 비밀번호 › 관리…에서 지우면 키체인에서도 사라져요.
- **다른 곳에 사본이 없어요.** Changmun에는 계정도 서버도 없어서 풀어 볼 암호화 사본도, 팔거나 유출되거나 물려받을 사본도 없어요. 개인정보 항목에 적은 요청 말고 앱이 스스로 가져오는 건 광고 필터 목록, 직접 요청한 Chrome 웹 스토어 확장 프로그램, 각 사이트의 아이콘(그 사이트에서 직접)뿐이고, 어느 것에도 비밀번호는 실리지 않아요.
- **누가 풀 수 있나요.** 잠금을 푼 이 Mac뿐이에요. 비밀번호를 복사할 때, 페이지에 채울 때(설정 › 개인정보 › 비밀번호를 채울 때 Touch ID 요구, 기본으로 켜져 있어요. 한 번 확인하면 1분 안의 다음 채우기는 다시 묻지 않아요), AI가 대신 로그인할 때 Touch ID나 Mac 암호로 확인해요. 취소하면 아무것도 채우지 않아요.
- **AI는 받지 못해요.** `sign_in`에서는 Changmun이 직접 양식을 채우고, AI에게는 채웠다는 사실만 알려요. 비밀번호도 계정 이름도 주지 않아요. AI는 비밀번호 칸을 읽거나, 입력하거나, 키를 누를 수 없고, 스크린샷에서도 가려져요. 로그인한 뒤의 페이지를 읽는다면 그 페이지의 글은 다른 페이지와 똑같이 페이지 내용으로 가요.
- **Anthropic으로 가는 것.** 내가 쓴 메시지와 AI가 읽은 페이지가, 내 `claude` CLI를 거쳐 가요. 그게 전부예요. Changmun에는 Anthropic 키가 없고 Anthropic에 직접 요청하지도 않아요.
- **가져온 비밀번호.** 이 Mac에서 각 브라우저의 `Safe Storage` 키체인 키로 복호화하고(macOS가 먼저 물어요) 로그인 키체인에 저장해요. 그 과정에서 업로드되는 건 없어요.
- **프로젝트가 멈추면.** 팔 것도, 끌 것도 없어요. 서버도 계정도 누구의 데이터베이스도 없으니까요. 비밀번호는 키체인에 그대로 있고, 앱은 macOS가 돌아가는 한 계속 돌아가요. MIT 라이선스 오픈소스라 누구든 이 모든 걸 확인할 수 있어요. `Sources/Changmun/Logins.swift`부터 보면 돼요.

## 개발자용

```sh
scripts/test.sh            # unit tests (Swift Testing)
scripts/check-strings.sh   # every string the code uses is translated in every language
swift scripts/make-icon.swift
scripts/release.sh 0.2.0 notes.md   # checks, DMG, GitHub release, Homebrew tap
```

릴리스는 EdDSA 키로 Sparkle용 서명을 해요. 개인 키 파일의 경로를 `~/.config/changmun/sparkle.env`에 `SPARKLE_KEY_FILE=...`로 적어 두세요. 이게 없거나 `Resources/Info.plist`의 `SUPublicEDKey`와 맞지 않는 키면 `release.sh`가 실행되지 않아요. 이 파일은 오프라인에 따로 백업해 두세요. 잃어버리면 이미 설치된 앱을 다시는 업데이트할 수 없고, 유출되면 누구나 설치된 앱이 받아들이는 업데이트에 서명할 수 있어요.

UI 문구는 코드에서는 영어이고 `Resources/<language>.lproj/Localizable.strings`에서 번역해요. 새 문구는 여섯 개 표 모두에 추가하세요.

`scripts/headless.sh`는 테스트용 복사본인 `Changmun Headless.app`을 띄워요(위 AI 절의 `changmun headless`와는 프로필을 나누지 않아요. 그쪽이 에이전트용이에요). 테스트나 에이전트가 쓰는 화면 없는 Changmun이에요. 창은 화면 밖에 두고, 포커스를 가져가지도 소리를 내지도 않으며, `~/Library/Application Support/Changmun Headless`에 자기만의 프로필을 둬요. 키체인은 건드리지 않고, AI 확인 창·사이트 권한·JavaScript 대화상자에는 알아서 답해요(권한은 거부).

```sh
scripts/headless.sh start                                   # copy build/Changmun.app as the headless app and start it
scripts/headless.sh call open_tab '{"url": "example.com"}'  # the AI's tools: list_tabs, navigate, read_page, click…
scripts/headless.sh shot window.png                         # the whole window, sidebar included
scripts/headless.sh stop
```
