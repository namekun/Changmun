*Changmun*（창문）在韩语中是“窗户”的意思。作为浏览器的名字，可以说相当实在。它免费、开源，无需账号，也不做任何追踪。App 支持英语、韩语、日语、简体中文、西班牙语、德语和法语。

## 为什么选择 Changmun

- **轻巧。** Chromium 内核的浏览器各自带着一整份 Chromium，Changmun 则借用 macOS 自带的 WebKit 引擎（Safari 用的就是它）。下载只有约 3 MB（0.4.1 的 DMG 为 2.6 MB），更省电，引擎的安全修复会随 macOS 和 Safari 的更新送达。
- **像 Arc 和 Dia 的边栏。** 垂直标签页给标题留足了地方，另有磁贴式个人收藏、书签文件夹、标签页群组和空间。也可以在设置里把标签页改成顶部的横条。
- **会使用浏览器的 AI。** Claude 面板通过你已有的 `claude` CLI 阅读页面，并替你点按、输入。它肯出手，但不会擅自做主：遇到有风险的操作会先询问。
- **默认私密。** 没有账户、服务器或分析，也就没有什么需要注册的。广告和追踪器拦截已内置。
- **搬家，家当一起带。** 从 Safari 和 Chromium 内核浏览器导入书签和历史记录，Chromium 内核浏览器的密码和登录状态也能一并带来。Safari 的密码 macOS 不肯交给其他 App，只能留在原处。

## 安装

```sh
brew install --cask namekun/tap/changmun
```

需要 [Homebrew](https://brew.sh)、macOS 14 Sonoma 或更高版本，以及搭载 Apple 芯片的 Mac。App 使用 Developer ID 签名并经过 Apple 公证，所以可以直接打开。更新会在 App 内收到（Changmun › 检查更新…，默认自动）。Homebrew 只用于安装。

首次启动时，Changmun 会询问是否从你现在使用的浏览器导入书签和历史记录（Chromium 内核浏览器还包括密码和登录状态）。

### 从源码构建

你需要 macOS 14 或更高版本，以及 Xcode 或命令行工具。

```sh
git clone https://github.com/namekun/Changmun.git
cd Changmun
scripts/bundle.sh release   # makes build/Changmun.app
open build/Changmun.app
```

如果只安装了命令行工具，脚本会使用 macOS 26 SDK 进行构建（macOS 27 SDK 的 SwiftUI 宏插件只随 Xcode 提供）。构建产物会放在 `~/Library/Caches/Changmun/build`，避开 iCloud 桌面同步。

## 功能一览

### 边栏与标签页

- **边栏。** 把个人收藏、书签和已打开的标签页收在左边一列：个人收藏以磁贴显示，下面是书签文件夹和垂直标签页。拖移标签页可调整顺序，拖到个人收藏上则可固定。和 Dia、Arc 一样，个人收藏和书签各自保留自己的标签页：点按它们会切换到对应的标签页，而不是替换你正在阅读的页面（按住 ⌘ 点按则新建标签页）。把页面上的链接拖到边栏即可作为标签页打开，拖到个人收藏或文件夹上则会存进去。标签页菜单还能重新载入、复制、移到新窗口、共享或用其他浏览器打开。想给标签页另起个名字，就连按两下它的标题，或在菜单里选“重命名标签页…”；换页面、重启后名字都还在，AI 也照样能看到页面原本的标题。书签也能用同样的方法重命名（连按两下，或在菜单里选“重命名…”），个人收藏则从菜单里改；起的名字即使从那个浏览器重新导入也会保留。关闭整个组的标签页或删除书签后，几秒内可以撤销。世上没有后悔药，但这几秒钟里有。
- **地址栏想放哪就放哪。** 放在手最习惯的位置：可以像 Arc 一样放在边栏顶部的后退、前进按钮下方，也可以像 Dia 一样放在页面上方（设置 › 外观 › 地址栏位置）。只显示网站名称，指针移上去时才出现盾牌和星标。个人收藏中的页面会一直显示星标，点按即可移出个人收藏。
- **顶部标签条。** 比起竖排，更喜欢横条？在设置 › 外观 › 标签页布局里选“顶部”。地址栏上方会出现一条横向标签条：最前面是只有图标的磁贴式个人收藏，接着是当前空间的标签页，带网站图标、标题、关闭 × 和声音标记。标签页群组显示为一个彩色小标签，点按它会收起整个群组（你正在看的标签页仍然保留）。“+”按钮在标签页太多时依然可见，标签条可以左右滚动。中键点按关闭标签页，拖动调整顺序，双击重命名，右键菜单与边栏相同。边栏（书签、空间、下载、菜单）从地址栏左侧的按钮打开，盖在页面上方。默认仍是边栏布局。
- **书签文件夹。** 让书签保持你整理好的样子，又随手可及。导入的文件夹保留原来浏览器中的层级。常用的文件夹可以固定到边栏（右键点按或 … › 固定到边栏，或把文件夹拖到个人收藏下方），直接在原处展开。把书签拖到其他文件夹或个人收藏上，或用菜单里的移到来移动。其余书签在边栏底部的书签按钮中，并可搜索；旁边的 … 按钮可打开历史记录、已归档的标签页、专注模式和设置。
- **标签页群组。** 把相关的标签页放在一起，免得它们碍事。右键点按标签页 › 添加到新群组，起个名字，还能折叠；连按两下群组的标题（顶部标签条里是群组小标签）即可重命名。从群组内的标签页打开的标签页会加入该群组；用 ⌘⇧T 重新打开的标签页会回到原来的群组。拖动群组的标题即可移动它，拖到个人收藏或固定的文件夹上，则会连同标签页一起收进一个书签文件夹。
- **整理标签页。** 一键把零散的标签页分好组。“新建标签页”旁边的魔杖（窗口 › 整理标签页）挥一下，零散的标签页就会分组。开启 Apple Intelligence（macOS 26）后，由你 Mac 上的模型按主题分组并为群组命名，标签页的任何信息都不会离开这台 Mac。未开启时，互相打开的标签页和同一网站的标签页会分在一起。“撤销”可在几秒内恢复原状。从地址栏打开的新标签页会自动加入匹配的群组（可在设置 › 标签页中关闭）。
- **归档旧标签页**（默认关闭）。把一阵子没看的标签页收起来，而不是扔掉。超过设定时间（12 小时到 30 天，仅在 Changmun 运行期间计时）没有查看的标签页，会关闭并收进历史记录 › 已归档的标签页，随时可以重新打开并回到原来的群组。正在显示、正在播放、画中画、正在使用摄像头或麦克风、个人收藏以及私密浏览的标签页永远不会被归档。
- **休眠标签页。** 让后台标签页打个盹，把内存还给你。20 分钟没有查看的后台标签页，以及内存紧张时的所有后台标签页，都会释放其网页进程，当你回来时连同历史记录一起恢复。
- **命令栏**（⌘T）。一个输入框，包办搜索、输入地址、切换到已打开的标签页、查找书签和历史记录，以及向 AI 提问。

### 空间与配置文件

- **空间。** 为不同的上网场景分别准备各自的标签页、标签页群组和个人收藏，上班用的标签页不会跟着你过周末。边栏最下面一行用来切换空间：点按圆点、按 ⌃1–⌃9，或在边栏上用两指横向轻扫（窗口 › 下一个空间、上一个空间、新建空间…）。每个空间都有各自的标签页、标签页群组、个人收藏和固定的文件夹，并为边栏轻轻染上自己的颜色。书签资料库、历史记录和已存储的密码是共用的。创建空间时打开“单独保存登录和 Cookie（配置文件）”，它的 Cookie 和网站数据也会单独保存，这样同一个网站可以同时登录两个账户；之后无法更改，删除配置文件时也会清除它的 Cookie 和网站数据。第一个空间由你原有的数据创建。私密浏览窗口没有空间。AI 可以看到普通空间的标签页（并标明空间名称），但配置文件空间的标签页只有在你身处该空间时才看得到。

### 阅读与观看

- **阅读模式。** 把文章当作干净易读的文字来读。⇧⌘R（Chrome 风格快捷键下为 ⌥⌘R）会把它显示在页面上方。页面像文章时，地址栏会出现一个按钮。按 Esc、点 ×，或再按一次同一个快捷键，页面就会原样恢复。这由页面里的一小段脚本完成：文章里的图片仍从页面原本加载它们的地方加载，除此之外不会下载或发送任何内容。
- **翻译页面。** 不离开页面，就能读另一种语言的内容。直接在原页面上使用 macOS 的本地翻译完成（⌥⌘T，需要 macOS 26 或更高版本）。链接和版式保持不变，文本不会离开这台 Mac。
- **分屏浏览**（⌥⌘\\）。一个页面不够用时，把两个标签页并排显示。
- **专注模式**（⌘⇧F）。隐藏页面以外的所有内容。能不能专注，还得看你自己。
- **链接预览。** 不离开当前页面，先看一眼链接。⇧ 点按链接会在浮动卡片中打开，按 ⌘↩ 可保留为标签页。
- **画中画**（⌃⌘P）。离开标签页后仍能继续看视频。你离开正在播放视频的标签页时会自动开启。即使在其他 App 里，⌃⌘← / ⌃⌘→ 也能快退或快进 5 秒，点按“返回标签页”则会把该标签页切换到前台。

### 隐私与安全

- **私密浏览窗口。** 浏览完不留痕迹：Cookie 和网站数据只保存在内存中，关闭后即忘；不会写入历史记录、会话，也不会交给 AI。
- **网站设置。** 在一个地方查看和调整 Changmun 为每个网站记住的内容。点击地址栏左侧的锁形图标，会弹出一个小面板，汇总 Changmun 为该网站记住的内容：广告拦截、缩放、弹出式窗口、摄像头和麦克风，以及它的标签页能否休眠。点击地址栏的其他位置（包括网站名称）仍然是编辑地址。
- **密码。** 记密码是钥匙串的活儿，你不用操心。密码在你登录后保存到钥匙串（仅限 https），并通过地址栏中的钥匙按钮填入。拷贝或填入密码时需要触控 ID 或 Mac 密码验证（填入时的验证可在设置 › 隐私中关闭）。
- **弹出式窗口。** 页面别想不请自来地弹出窗口。未经点按就打开的弹出式窗口会被拦截，页面上方会显示“打开”和“始终允许此网站”。

广告和追踪器拦截见下面的[广告拦截](#广告拦截)，哪些内容留在你的 Mac 上、哪些会发送出去，见[隐私](#隐私)。

### 存储与下载

- **存储页面。** 把页面存成 PDF 或图片，留作日后查看。文件 › 存储为 PDF… 会把页面存成一页很长的 PDF，文件 › 捕获整个页面… 会把整个页面（而不只是屏幕上看到的部分）存成一张图片。两者也都在标签页的菜单中；除非另选位置，否则存储到“下载”文件夹，在私密浏览窗口中同样可用。在内部容器中滚动的页面和滚动时才加载的图片，可能无法完整捕获。
- **下载。** 随时看到下载进度，首次打开时还有安全检查。进度显示在边栏底部；下载的文件会带上 Safari 的隔离标记，因此首次打开时 Gatekeeper 会进行检查。App、脚本和安装程序只会在 Finder 中显示，不会直接运行。中断的下载可以在该行点按“重试”，从中断处继续。
- **页面缩放。** 调整一次，该网站就一直保持这个缩放。页面缩放按网站记忆，所以只需眯一次眼。
- **会话保存。** 浏览器也有崩溃的时候。已打开的标签页每 15 秒保存一次，所以崩溃几乎不会损失什么。

### 更新

- **自动更新。** Changmun 通过 Sparkle 自行更新。它每天在后台检查一次，有新版本时询问你是否安装；选取 Changmun › 检查更新… 可立即检查。更新带有签名，只有与 App 内置密钥相符的才会安装。可在设置 › 高级中关闭自动检查，或让它自动下载并安装。

## AI

右侧的面板 (⌘E) 使用你已有的 `claude` CLI，因此直接消耗你的 Claude Code 订阅。默认模型是 Sonnet。输入框下方的菜单（显示为“Sonnet · 高”这样）可以选模型和推理强度（自动、低、中、高、极高、最大）；强度会传给 Claude Code 的 `--effort`，选自动则什么都不传。模型也可以在设置 › AI 里切换。

面板顶部显示对话的标题（也就是第一条消息）。它的菜单列出最近的对话和“显示全部对话”，旁边是新建对话按钮，以及把面板移到独立窗口的弹出按钮。关闭那个窗口，面板就回到浏览器窗口里。提问和批准卡片在独立窗口里同样可用，AI 要询问时窗口会跳到最前面。工作时会显示“已处理 12 秒”，下面是实时的步骤（可展开）。你的消息下会附上随它一起发送的页面卡片（标题和网站）。一个小圆环显示这段对话用了多少模型上下文，指针悬停可看百分比。

AI 通过以下工具操作浏览器：`list_tabs`、`open_tab`、`switch_tab`、`close_tab`、`navigate`、`go_back`、`go_forward`、`reload`、`read_page`、`read_tabs`、`click`、`click_at`、`type_text`、`press_key`、`select_option`、`hover`、`drag`、`wait_for`、`scroll`、`screenshot`、`sign_in`。密码、一次性验证码和银行卡栏位，它无法读取其值、无法输入或按键，截图中也会被遮住。它也无法上传文件。

- `read_page` 在每个元素后用方括号写出状态：`[checked]`/`[unchecked]`、`[selected]`、`[expanded]`/`[collapsed]`、`[disabled]`、`[focused]`、`[pressed]`、`[required]`、`[invalid]`。输入框和列表的当前值也会写成一行，但密码、验证码和银行卡栏位永远不显示值。
- 在 `click`、`click_at`、`type_text`、`press_key`、`select_option`、`hover`、`drag` 之后，页面稳定下来（最多约 1.5 秒），会返回自 AI 上次查看以来的变化：地址和标题是否变了，以及新出现的（`+`，编号接着往下排，可立即使用）、变化的（`~`）和消失的（`-`）元素。最多 40 行；若页面发生了跳转，只会说明这一点并建议用 `read_page`。这与读取一样会被记录。 仅焦点的变化放在最后，不占 40 行；不应答的框架会被跳过并说明；重新出现的元素（再次打开的菜单）会再次作为新元素列出。
- `screenshot` 加上 `labels` 会重新读取页面，并在图片上为视野内的每个元素画出与 `read_page` 相同编号的方框。不会向页面添加任何东西，只画在图片上。方框的位置取决于页面的布局，因此对元素的描述以 `read_page` 为准。也可以用 `changmun screenshot --labels`。
- 每个工具都接受可选的 `title`（例如“正在比较价格”），会原样显示在面板的进度行里；没有时显示 Changmun 生成的文字。它是模型写的文字，所以会整理成一行、最多 60 个字符，并且不参与任何询问或判断。 标题排在 Changmun 自己的文字之后（“正在点击“购买” · 正在比较价格”），绝不取代它；`sign_in` 和每次都要询问的操作只显示 Changmun 自己的文字。
- AI 工作时输入框仍可发送。回车会把消息排成小标签，等本次运行顺利结束后按顺序发出（带着你写下它时的标签页）；若运行失败或被中断，会出现“发送队列”按钮等你确认。⌘回车则会像“停止”一样停下当前运行，并立刻在同一对话中接着发送新消息。停止和新对话会清空队列。 最多排 8 条（超过会有一行提示）；等待期间第二次 ⌘Return 会并入第一次；中断后若无法继续原来的对话，消息会作为新对话重发，面板会说明。使用输入法（韩语、日语、中文）输入时，Return 属于输入法，不会发送。
- `sign_in` 会把已保存的登录信息填入表单，而不让 AI 看到。页面的确切主机必须与已保存登录的主机一致（仅限 https），私密窗口中不可用。每次都会询问“允许 AI 以某账号登录某网站吗？”，并用 Touch ID 或 Mac 密码确认（有多个账号时由你在窗口里选择）。没有保存的登录信息、你拒绝、没有回应或验证失败时，AI 听到的都是同一句“登录没有完成”，所以无法探出你有哪些账号。AI 拿不到密码，也拿不到账号名。它不会点击按钮；之后的点击由 AI 完成，并像其他点击一样受到检查。 没有已保存登录时也会弹出窗口（只能关闭），AI 同样等待；在同一对话里拒绝某网站后不再弹窗，而是固定等待四秒并在面板里提示。表单的提交地址或任何提交按钮（无论在哪里）指向其他网站时会被拒绝。

要跨多个标签页完成任务，可在输入框的 + 菜单里用“添加标签页…”添加它们（逐个添加、整个标签页群组，或所有已打开的标签页）。添加的标签页显示为可移除的小标签，AI 会用 `read_tabs` 一并读取，读取前不再询问。添加两个或更多时，面板会建议比较它们，或分别总结每个标签页的要点。

AI 正在看的标签页会以小标签显示在聊天下方那一行，在输入框里输入 @ 还能再附上别的标签页。⌘E 把光标放进输入框（在输入框里再按一次会关闭面板），Esc 停止运行（输入框里的停止按钮也行），↑ 调出上一条消息，拖动面板左边缘可以调整宽度。建议会贴合你正在看的页面；在页面右键菜单里选“就所选内容询问 AI”，选中的文字会作为引用放进输入框。

回答里的代码块、列表和表格都会正常显示，代码带复制按钮。链接旁会写出它真正通向的网站；对话读过其他网站之后，打开回答里的链接也会先询问。较长的任务会折叠成“12 个步骤”，并附一行打开和关闭了几个标签页，被 AI 关掉的标签页可以用“重新打开”找回。Claude Code 没登录、用量额度用完，或者网络、服务器出问题时，面板会用大白话说明原因，并给出“重试”。

+ 菜单里的“附加截图”会附上你正在看的页面（页面上的敏感栏位会被遮住），“添加图片…”会添加 Mac 上的图片，也可以把图片拖进或粘贴到面板里：每条消息最多 4 张，长边缩到 1568 像素并重新保存，文件里带的拍摄地点和时间不会保留。图片也算 AI 读过的内容（截图算那个页面，其他图片算“你添加的图片”），所以它之后的操作，会像读过其他网站之后那样先询问。麦克风按钮会启动 macOS 听写。

结束的对话只保存在这台 Mac 上，可以在面板顶部的对话菜单（显示全部对话）里重新阅读。它们只读，不能接着继续（接着继续的话，AI 还记得以前读过的页面，Changmun 却不再知道那是哪些网站，“读过其他网站之后先询问”就会被跳过），私密窗口里的对话从不记录。输入或选择的文字只保存字数，地址只保留 ? 或 # 之前的部分。可以在设置 › AI › 保留对话记录中关闭，也可以在面板里逐个或全部删除。

为了避免页面里暗藏的指令让它把读到的内容带到别处，Changmun 会先征求你的同意。询问的频率有三档，在输入框下方的批准菜单或设置 › AI 里选（取代原来的开关，已有的设置会沿用）：

- **读取其他网站后询问**（默认）。询问下面列表里的全部情形。
- **每次操作前都询问**。即使对话没读过其他网站，在页面上输入、选择或点击之前也会询问。可以在该网站上允许到对话结束。
- **仅对无法撤销的操作询问**。跳过下面列表里的前三项，只询问后两项。

90 秒内没有回应则视为拒绝。下面列表里，前三项是默认模式的询问，后两项在任何模式下都会询问：

- 使用你没在看的标签页之前，每个标签页和网站只问一次；
- 打开某个地址之前，除非是搜索、已经打开过、访问过或已加入书签的地址，或是知名网站的首页；
- 在对话已读取过其他网站之后，每一次点击、按键、悬停、拖放、输入文字和选择选项之前都会询问，并显示它将要做的事。你可以只允许这一次，或在该网站上允许到对话结束。滚动、查看前台页面（读取、截图、等待、标签页列表）、后退、前进和刷新都不会询问。新建对话 (⌘⇧E) 会重新开始。
- 看起来像付款、下单、发送、发布、评论、分享、上传、授予访问权限（允许、连接、授权）、删除、取消、注销这类无法撤销或会交出东西的操作，无论你允许过什么，每次都会询问（只能允许一次或不允许）。消息框里的回车、发送到其他网站的表单、文本框之外的 Delete 和 Backspace 也一样。
- Cookie 横幅的接受、允许、同意，以及保存、清除、重置、屏蔽这类设置，每个网站询问一次。在 AI 面板里可以在该网站上允许到对话结束，MCP 代理则可在该连接持续期间（即该 Claude Code 会话的 MCP 服务器结束前）允许；命令行每次都会询问。

在面板里，AI 的询问会以输入框上方的卡片出现，而不是盖在页面上的窗口。回车或 Esc 是“不允许”，⌘回车是“允许一次”，⌥⌘回车是在这个对话里允许该网站。表示同意的按键只在光标位于面板内、且卡片出现半秒之后才有效，所以为别的事按下的键不会被当成回答。涉及付款、删除、登录的询问，以及只有页面标记自称是 Cookie 横幅的按钮，仍然以窗口形式弹出，那里没有任何按键表示同意。面板顶部会显示这个对话读过什么（“已读取 3 个网站 · 已允许 1 个”），点开可以看到你允许过的网站，每个都有“撤销”。

其他智能体（例如 Claude Code）也可以通过 MCP 使用同样的工具，同样会有这些询问：

```sh
claude mcp add changmun -- /Applications/Changmun.app/Contents/MacOS/Changmun --mcp
```

如果 Changmun 没有运行，`--mcp` 会将其启动。控制服务器只监听 127.0.0.1，并需要一个每次启动都会变化的令牌。

任何能运行命令的代理也可以在 shell 中使用（Homebrew 会把 `changmun` 放到 PATH 中）：

```sh
changmun tabs
changmun open example.com
changmun read
changmun read-tabs 3 5
changmun click 12
changmun type 3 "hello" --submit
```

其余命令见 `changmun help`。每条命令调用一个相同的工具，经过同样的确认，必要时会启动 Changmun。

### 给智能体用的无界面 Changmun

智能体在你正用的浏览器里一遍遍问你，很快就让人心累。所以我们另备了一个没有窗口的 Changmun：看不见，不抢焦点，也不出声，配置也是独立的，里面没有你的 Cookie、历史记录、密码和钥匙串。

```sh
changmun headless start     # 把你运行命令的这个应用复制到 ~/Library/Application Support/Changmun Agent 并启动
changmun headless status    # 是否在运行、pid、版本、配置文件夹
changmun --headless open example.com
changmun --headless read
changmun headless stop
claude mcp add changmun-headless -- /Applications/Changmun.app/Contents/MacOS/Changmun --mcp --headless
```

任何命令加上 `--headless`，就会发给它，而不是你正用的浏览器；MCP 的写法是 `--mcp --headless`。没在运行时，两者都会先把它启动。在这里，AI 使用其他标签页、打开新地址、读过其他网站后再操作之前，都不会询问：这些用来防范网页暗藏指令的询问是关闭的。所以它是一个配置为空的独立副本，并且会拒绝无法撤销的操作：看起来像付款、下单、发送、发布、删除或授予访问权限的操作，以及只是被网页自称为 Cookie 横幅的区域里的操作，都会收到“需要真人”的错误，因为没有人在旁边看着，而你在里面登录过的网站就等于交给了 AI。其余一律放行。网站权限（摄像头、位置等）一律拒绝。副本由运行命令的应用生成，该应用换了版本就会重新生成（`changmun headless status` 会告诉你）；它自己不会更新。

## 广告拦截

Changmun 会把 EasyList（广告）和 EasyPrivacy（跟踪器）转换为 WebKit 内容拦截规则，并每 4 天更新一次。在设置 › 隐私中，你可以关闭某些列表，或通过网址添加其他列表（一键即可添加韩国广告列表）。如果某个网站出现异常，可用地址栏中的盾牌按钮仅对该网站关闭拦截。WebKit 无法表达的规则（正则表达式、`$redirect`、scriptlet、`:has-text` 及其他扩展选择器）会被跳过，而不是凭猜测处理。漏掉一条广告，总好过把页面弄坏。

## 扩展

在设置 › 扩展中管理（网页扩展需要 macOS 15.4 或更高版本）。

在配置文件空间的标签页中，扩展可以运行，但扩展的 Cookie API 只能看到默认数据存储，看不到配置文件的。

- **来自 App Store 的 Safari 扩展**安装后会自动显示，开启时会请求所需权限。
- **Chrome 网上应用店的扩展**：打开扩展的商店页面，页面上方会出现“添加到 Changmun”（也可以在设置中粘贴其网址或 ID）。Changmun 会将其解包到 `~/Library/Application Support/Changmun/Extensions`，并作为 WebKit 扩展载入；再次添加即可更新。
- **Safari 内容拦截器**（Unicorn、AdGuard 等）：macOS 只允许 Safari 向拦截器索取规则，因此 Changmun 会读取拦截器保存的规则文件。macOS 会询问一次是否允许其读取其他 App 的数据。
- 未打包的扩展文件夹（含 `manifest.json`）同样可以载入。与原生 App 通信等部分功能可能无法使用。

## 从其他浏览器导入

首次启动时，或通过菜单，Changmun 可以从 Safari 和 Chromium 内核浏览器导入书签和历史记录：Chrome、Arc（含其边栏）、Dia、Aside、Whale、Brave、Edge、Vivaldi。对于 Chromium 内核浏览器，还会一并带入密码和 Cookie，让你保持登录。

- 密码和 Cookie 通过各浏览器的钥匙串项目（`<name> Safe Storage`）解密，因此 macOS 会请求你的许可。导入的密码会存入登录钥匙串，标签为 `Changmun`。
- 读取 Safari 需要完全磁盘访问权限。macOS 不会把 Safari 的密码交给其他 App。

## 隐私

- 你的浏览数据只保留在你的 Mac 上。Changmun 没有账号、服务器或统计分析。
- 检查更新会从 GitHub Pages 获取一份很小的发布列表（`appcast.xml`）。GitHub 和任何网站服务器一样会收到这个请求，能看到 Changmun 的名称和版本；会附带 Mac 详细信息的 Sparkle 系统资料已关闭，并保持关闭（可在设置 › 高级中关闭检查本身）。
- 搜索建议会把你在命令栏中输入的内容发送给你的搜索引擎（可在设置中关闭；私密浏览窗口中从不发送）。
- AI 面板会通过 `claude` CLI 把你的消息、你附上的图片和 AI 读取的页面内容发送给 Anthropic。整理标签页和页面翻译都在你的 Mac 上运行。

## 密码与安全

对会同步密码的浏览器，人们常问一个很合理的问题：我密码的加密副本如果在你们的服务器上，公司能不能解密、冒充我登录，或者在公司倒闭时把它卖掉？对 Changmun 来说，答案很简短，下面每一条都对照代码核实过。

- **存在哪里。** 存在这台 Mac 的登录钥匙串里，是标签为 `Changmun` 的互联网密码（可在“钥匙串访问”中搜索）。Changmun 不会把它们标记为可同步，所以 iCloud 钥匙串也不会把它们带到别处。在设置 › 隐私 › 已存储的密码 › 管理…中删除后，钥匙串里也就没有了。
- **别处没有副本。** Changmun 没有账号，也没有服务器，所以不存在可供解密、出售、泄露或继承的加密副本。除了“隐私”一节列出的请求，应用自己获取的只有广告过滤列表、你要求安装的 Chrome 网上应用店扩展，以及各网站自己的图标（直接来自该网站），其中都不含密码。
- **谁能解密。** 只有这台已解锁的 Mac。拷贝密码时、把密码填入页面时（设置 › 隐私 › 填写密码时需要触控 ID，默认开启；验证一次后，接下来一分钟内的填入不会再询问），以及 AI 替你登录时，都会要求触控 ID 或 Mac 密码。取消就什么也不填。
- **AI 拿不到。** 对于 `sign_in`，Changmun 自己填写表单，只告诉 AI 已经填好，不告诉它密码或账号名。AI 不能读取密码栏、不能在其中输入或按键，截图里也会被遮住。如果它随后读取登录后的页面，那个页面的文字和其他页面内容一样处理。
- **发往 Anthropic 的内容。** 你的消息、你附上的图片和 AI 读取的页面，经由你自己的 `claude` CLI 发出，仅此而已。Changmun 不持有 Anthropic 密钥，也不会自己向 Anthropic 发请求。
- **对话记录。** 结束的对话只存在这台 Mac 的一个文件里（可在设置 › AI 中关闭），不含输入的文字和地址中 ? 或 # 之后的部分，私密窗口里的对话从不记录。
- **导入的密码。** 在你的 Mac 上用各浏览器的 `Safe Storage` 钥匙串密钥解密（macOS 会先询问），再存入登录钥匙串。中途不会上传任何东西。
- **项目停了会怎样。** 没有什么可卖，也没有什么可关：没有服务器，没有账号，没有任何人的数据库。你的密码仍在你的钥匙串里，只要 macOS 还能运行，应用就能继续运行。它以 MIT 许可开源，任何人都能核实这一切，可以从 `Sources/Changmun/Tabs/Logins.swift` 看起。

## 面向开发者

```sh
scripts/test.sh            # unit tests (Swift Testing)
scripts/check-strings.sh   # every string the code uses is translated in every language
swift scripts/make-icon.swift
scripts/release.sh 0.2.0 notes.md   # checks, DMG, GitHub release, Homebrew tap
```

发布版本用 EdDSA 密钥为 Sparkle 签名。把私钥文件的路径以 `SPARKLE_KEY_FILE=...` 写进 `~/.config/changmun/sparkle.env`；没有它，或密钥与 `Resources/Info.plist` 中的 `SUPublicEDKey` 不符时，`release.sh` 不会运行。请把这个文件离线备份。丢失后，已安装的副本将永远无法再更新；泄露后，任何人都能签出它们会接受的更新。

界面文本在代码中是英文，翻译放在 `Resources/<language>.lproj/Localizable.strings` 中；新增的每条字符串都要加进全部六个表。

`scripts/headless.sh` 运行的是测试用副本 `Changmun Headless.app`（它与上文 AI 一节里面向智能体的 `changmun headless` 从不共用配置），即为测试和智能体运行的无界面 Changmun：不在屏幕上显示，从不抢占焦点或发出声音，使用 `~/Library/Application Support/Changmun Headless` 中独立的配置。它不会触碰钥匙串，并会自行应答 AI 确认、网站权限和 JavaScript 对话框（权限一律拒绝）。

```sh
scripts/headless.sh start                                   # copy build/Changmun.app as the headless app and start it
scripts/headless.sh call open_tab '{"url": "example.com"}'  # the AI's tools: list_tabs, navigate, read_page, click…
scripts/headless.sh shot window.png                         # the whole window, sidebar included
scripts/headless.sh stop
```
