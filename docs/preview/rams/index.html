Good design is as little design as possible.

A setting stays if removing it would strand someone (privacy, security, what leaves the Mac, Claude usage, accessibility, hardware); only layout and habit choices the app can decide once go.

These are only proposals.

Each cut removes a setting someone may use. Nothing in the app has changed.
