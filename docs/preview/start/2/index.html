Changmun · 시작 페이지 시안 2차

내 방식대로 고르고, 끄고, 옮기는 시작 페이지

지난 시안의 대시보드(B)를 기본값으로 두고, 조용히(A)와 AI 먼저(C)도 고를 수 있게 했어요. 구성 요소를 켜고 끄고 끌어서 옮기고, 배경과 새 탭이 열리는 곳도 바꿀 수 있어요. 모든 화면은 실제 앱 창(1440×900) 위에 올렸고, 이미지를 누르면 원본이 열려요.

기본값 · 대시보드 · 구성 요소 전부 켜짐(비어 있으면 알아서 숨김) · 배경 스페이스 색 · 새 탭은 시작 페이지
1 · 스타일

대시보드 · 조용히 · AI 먼저

작은 실물 썸네일 셋 중에 골라요. 스타일마다 구성 요소 설정을 따로 기억해요.

 2 · 구성 요소

켜기·끄기·끌어서 순서

즐겨찾기, 이어서 보기, 읽기 목록, 자주 방문, AI 제안. 톱니로 줄 수나 개수를 바꿔요.

 3 · 배경

색 번짐 · 단색 · 내 이미지

이미지는 이 Mac에만 저장되고, 글자가 묻히지 않게 보호막이 자동으로 깔려요.

 4 · 새 탭

어디가 열릴지

시작 페이지, 명령 막대, 빈 페이지, 내가 정한 주소.
여는 곳

세 군데에서 같은 설정으로 들어가요

시작 페이지 오른쪽 아래의 “맞춤 설정” 알약, 각 구성 요소 머리글의 “편집”, 그리고 설정 › 시작 페이지예요. 앞의 둘은 같은 팝오버를 열고, 설정 화면은 같은 컨트롤에 실시간 미리보기를 더한 것이에요.

1알약은 포인터가 페이지에 있거나 키보드 포커스가 들어올 때만 나타나요(지금은 올려 둔 모습). 2구성 요소 머리글에 올리면 “편집”이 나타나고, 누르면 팝오버가 그 구성 요소의 톱니를 펼친 채로 열려요.

페이지가 비어 있는 첫 실행 화면에서는 알약이 늘 보여요. 지울 것이 없어도 “여기서 바꿀 수 있다”는 단서가 되어 줘요.

맞춤 설정 창

360pt 팝오버 하나에 다 들어 있어요

알약에 붙어 위로 열리는 팝오버예요. 위에서부터 스타일, 구성 요소, 배경, 새 탭 열기이고, 아래에 “기본값으로 되돌리기”가 고정돼요. 변경은 바로 적용되고 뒤의 페이지가 그대로 바뀌어서 “완료”는 그냥 닫기예요. 창이 낮으면 가운데 부분만 스크롤돼요.

기본 상태. 스타일 썸네일 셋은 지금 설정(배경 포함)으로 그린 실물이에요. 선택된 것은 설정 › 모양의 테마 타일과 같은 파란 테두리를 써요.

구성 요소의 톱니

톱니를 누르면 그 행 아래로 옵션이 펼쳐져요(한 번에 하나만). 즐겨찾기는 줄 수와 이름 표시, 이어서 보기는 보여 줄 종류, 읽기 목록은 안 읽은 것/전체, 자주 방문은 4개/8개예요. 끄면 톱니가 숨어요.

끌어서 순서 바꾸기

읽기 목록을 위로 끄는 중. 잡은 행은 떠오르고(그림자와 살짝 커짐) 놓을 자리에는 점선 구멍이 열려요. 뒤의 시작 페이지는 이미 새 순서로 다시 배치돼 있어서, 놓기 전에 결과를 볼 수 있어요.

키보드와 VoiceOver

손잡이에 포커스가 가면 파란 링이 보이고 ⌥↑/⌥↓로 한 칸씩 옮겨요. VoiceOver는 “읽기 목록, 순서 바꾸기 손잡이, 5개 중 4번째”라고 읽고, 옮길 때마다 새 위치를 알려요.

스타일

세 스타일, 각각 두 가지 꾸밈

같은 설정 부품으로 얼마나 다르게 만들 수 있는지 보여 드려요. 구성 요소 설정은 스타일마다 따로 기억되고, 배경과 새 탭 열기는 모두 함께 써요.

대시보드 기본값

읽기 목록을 맨 위로 올리고 자주 방문을 껐어요. 혼자 남은 반쪽 구성 요소는 가로로 넓어져 2열로 흘러요.

기본 배경(중립), 즐겨찾기 두 줄(타일이 더 커져요), 이어서 보기만 켜 두었어요.

조용히

내 이미지(라이트는 새벽 능선, 다크는 오로라로 보여 드려요)에 흐림 6. 검색창과 칩은 유리 판이 되고 타일 이름에는 은은한 후광이 생겨요.

즐겨찾기 두 줄(4+4)과 읽기 목록을 켰어요. 조용히 스타일은 켜진 구성 요소를 좁은 한 단으로 쌓아요.

AI 먼저

단색 “이끼”. 라이트와 다크에서 각각 어울리는 톤으로 바뀌어요. AI 제안은 프롬프트 바로 아래 카드 4개로 나와요.

AI 제안을 끄고 이어서 보기를 켠 모습. 구성 요소가 늘면 위에서부터 쌓이고 세로 가운데 정렬은 풀려요.

배경

다섯 가지, 그리고 글자는 늘 읽혀야 해요

스페이스 색(기본, 지금의 번짐), 기본(중립), 단색, 이미지, 없음이에요. 이미지와 단색은 라이트·다크 모두에서 글자 대비를 지켜요.

단색

동그라미마다 라이트(왼쪽 위)와 다크(오른쪽 아래) 톤이 반반 들어 있어요. 고르면 그 둘이 모드에 맞춰 바뀌어요. 맨 끝은 사용자 지정(시스템 색상 선택기)이에요.

내 이미지

파일을 고르면 썸네일, 이름, 크기, 이 Mac에만 저장된다는 표시, 다른 이미지…/삭제, 흐림(0–40)과 옅게·어둡게(0–60) 슬라이더, 자동 보호막 안내가 나와요. 라이트 모드의 두 번째 슬라이더는 이미지를 하얗게 옅게 하고, 다크 모드에서는 어둡게 해요.

한 이미지를 두 모드가 함께 쓰니, 어두운 이미지를 라이트에서(또는 밝은 이미지를 다크에서) 보면 보호막이 50%까지 올라가요. 이때는 노란 안내로 “다른 모드에서 보면 더 선명해요”라고 알려요.

글자 보호막

일부러 가장 나쁜 이미지(색종이)로 실험했어요. 왼쪽은 아무것도 깔지 않은 모습, 오른쪽은 자동 보호막 + 흐림 10 + 유리 판. 위에서부터 쌓는 차례는 이미지 → 흐림 → 옅게/어둡게 → 자동 보호막(밝기와 복잡도로 계산, 가운데가 더 짙음) → 카드·검색창·칩의 유리 판이에요.

1평소 2짧은 변이 1600px 미만이면 “이미지가 작아요” 3복잡한 무늬면 흐림을 자동으로 올리고 이유를 알려요.

보호막 규칙(제안)

  • 이미지를 가져올 때 64×40으로 줄여 평균 밝기와 복잡도(국소 대비)를 한 번만 계산해 저장해요.
  • 라이트/다크마다 본문 글자(보조 글자 기준) 대비 4.5:1을 목표로 보호막 농도를 정해요. 바닥색은 라이트에서 흰색, 다크에서 거의 검정이에요.
  • 농도는 10%에서 72% 사이. 72%로도 못 맞추면 노란 안내를 보여요.
  • 카드·검색창·칩은 이미지 위에서만 유리 판(반투명 + 블러)이 돼요. 투명도 줄이기를 켜면 불투명 판이에요.

이미지 처리(제안)

  • 원본은 건드리지 않고, 가져올 때 긴 변 3840px 이하로 줄인 복사본을 앱 데이터 폴더에 한 장만 저장해요.
  • 원본을 옮기거나 지워도 배경은 그대로예요. 이름만 표시용으로 기억해요.
  • 복사본이 없어지거나 깨지면 스페이스 색으로 돌아가고 팝오버에 알려요.
  • 개인 창은 배경을 쓰지 않고 중립이에요.
새 탭

새 탭은 어디에서 열릴까요

네 가지 중 하나예요. 시작 페이지(기본), 명령 막대, 빈 페이지, 그리고 Safari의 홈페이지처럼 내가 정한 주소.

“주소 지정”을 고르면 입력칸이 열려요. 올바른 https 주소면 사이트 아이콘과 체크가 보이고, 아래에 한 줄 안내가 늘 붙어요.

1비어 있으면 시작 페이지를 열어요 2형식이 틀리면 빨간 테두리와 이유 3http는 노란 안내와 “https://로 바꾸기” 4올바른 주소.

입력 규칙(제안)

  • 입력 중에는 검증하지 않고, 포커스가 나가거나 ⏎를 누를 때 확인해요(빨간 글씨가 타이핑 중에 깜빡이지 않게).
  • 스킴이 없으면 https://를 보충해요(“example.com”은 https://example.com).
  • http는 막지 않고 권고만 해요. 사내 주소처럼 https가 없는 곳도 있으니까요.
  • 검증은 형식만 봐요. 실제로 열리는지는 확인하지 않아요(요청이 나가기 때문).

이렇게 동작해요

  • 한 줄 안내: “이 사이트는 새 탭을 열 때마다 불러와요.” 설정 화면에는 접속 사실(IP 포함)을 사이트가 알게 된다는 설명까지 붙여요.
  • 탭이 하나도 없는 창은 이 설정과 상관없이 시작 페이지를 보여요(창을 열 때마다 사이트가 불려 나가지 않게).
  • 주소 지정에서는 시작 페이지를 안 쓰므로 ⌘T 직후 검색창 포커스는 지정한 사이트가 가져가요.
  • 개인 창은 따로 질문으로 남겨요(아래).
설정 화면

설정 › 시작 페이지

설정의 “탭” 아래에 새 페이지를 추가해요. 팝오버와 같은 컨트롤이지만 더 넉넉하고, 위에 실시간 미리보기(실제 시작 페이지를 축소해 그려요)가 있어요. 구성 요소 옵션은 톱니 대신 행에 바로 드롭다운으로 보여요. 현재 설정 창은 720×520pt라 이 페이지는 스크롤돼요. 이해를 돕기 위해 높이를 키워서 그렸어요.

미리보기는 아래 컨트롤을 만질 때마다 바뀌어요. 스타일은 라디오 행(설명 포함)이에요.

배경(이미지 상태), 새 탭 열기(주소 지정, http 경고), 초기화. 이 화면에서 쓰는 이미지는 새벽 능선(라이트)/오로라(다크) 예시예요.

동작

어떻게 움직이나요

저장
바꾸는 즉시 적용되고 즉시 저장돼요. “완료”는 팝오버를 닫을 뿐 취소가 아니에요(Esc도 같아요). 설정 값은 기존 환경설정 파일에 들어가요.
스타일
스타일을 바꾸면 그 스타일이 마지막으로 쓰던 구성이 나타나요. 처음엔 프리셋이에요. 대시보드는 모두 켬, 조용히는 즐겨찾기만, AI 먼저는 AI 제안과 즐겨찾기. 배경과 새 탭 열기는 스타일과 상관없이 공통이에요.
켜기·끄기
끄면 행이 흐려지고 톱니가 숨어요. 켜져 있어도 보여 줄 데이터가 없으면 페이지에서는 숨겨지고(적응형), 팝오버 행에는 “지금은 비어 있어요” 보조 문구가 붙어요.
끌어서 순서
손잡이를 잡으면 행이 떠오르고 놓을 자리가 점선으로 열려요. 뒤 페이지가 실시간으로 재배치되고, 놓으면 앱의 스프링(감쇠 1.0)으로 자리 잡아요. 검색창은 목록에 없고 늘 맨 위예요. 읽기 목록과 자주 방문처럼 반쪽 너비 구성 요소가 이웃하면 나란히, 혼자면 넓게 보여요. AI 먼저 스타일에서 AI 제안은 항상 프롬프트 바로 아래예요.
옵션(톱니)
한 번에 한 행만 펼쳐요. 즐겨찾기는 한 줄(모두 나란히) 또는 두 줄(균형 있게 반반, 타일이 더 커져요)과 이름 표시. 이어서 보기는 닫은 탭과 최근 페이지 또는 닫은 탭만(카드는 4개, 좁으면 3개). 읽기 목록은 안 읽은 것만 또는 전체. 자주 방문은 4개 또는 8개.
배경
스페이스 색(기본), 기본, 단색(8가지 + 사용자 지정), 이미지, 없음. 타일을 누르면 바로 바뀌고 이미지는 파일 선택창이 먼저 열려요(취소하면 이전 배경을 유지).
새 탭 열기
시작 페이지 · 명령 막대 · 빈 페이지 · 주소 지정. 바꾼 뒤의 ⌘T부터 적용돼요.
되돌리기
“기본값으로 되돌리기”는 스타일, 구성 요소, 배경, 새 탭 열기를 모두 처음으로 돌려요. 확인창 없이 바로 하고, 아래에 “기본값으로 되돌렸어요 · 실행 취소(⌘Z)” 토스트를 10초간 띄워요. 이미지 복사본은 그 사이에는 지우지 않아요.
개인 창
지금처럼 개인 창 안내 화면을 쓰고 배경·구성 요소 설정은 적용하지 않아요. 안내 화면의 메시지가 더 중요해서예요.
좁은 창·패널
AI 패널이 열려 페이지가 827pt가 되면 카드는 3개로, AI 제안 칩은 숨겨요(지난 시안과 같아요).
접근성

손으로 끌 수 없어도 똑같이 할 수 있어요

이름과 조작

  • 손잡이: 버튼으로 읽고, 이름은 “읽기 목록, 순서 바꾸기, 5개 중 4번째”. 동작 “위로 옮기기/아래로 옮기기”가 VoiceOver 로터에 나와요. 옮긴 뒤 “읽기 목록, 5개 중 3번째”라고 알려요.
  • 키보드: Tab으로 손잡이에 가면 ⌥↑/⌥↓로 한 칸씩, ␣로 켜고 끄기, 톱니는 ⏎로 펼쳐요. 순서는 완료 → 스타일 → 구성 요소(손잡이, 톱니, 스위치) → 배경 → 새 탭 → 되돌리기.
  • 스위치: “읽기 목록 표시, 켜짐”. 톱니: “읽기 목록 옵션, 접힘/펼침”(펼침 상태를 알려요).
  • 스타일·배경 타일은 라디오 그룹이고 “대시보드, 선택됨”처럼 읽어요. 색 동그라미는 색 이름(“이끼”)으로, 슬라이더는 “흐림, 8, 0에서 40”으로 읽어요.

보는 방식

  • 색에만 기대지 않아요: 선택은 링과 굵은 글씨, 오류는 아이콘과 문장, 경고는 노란 아이콘과 문장이에요. 오류 문장은 나타날 때 VoiceOver가 바로 읽어요.
  • 동작 줄이기: 행이 떠오르거나 구멍이 열리는 움직임과 배경 전환 페이드를 끄고, 행은 즉시 제자리로 가요(놓을 자리는 선으로 표시).
  • 투명도 줄이기: 팝오버와 이미지 위의 유리 판을 불투명 판으로 바꾸고, 보호막 하한을 높여요.
  • 대비 높이기: 보조 글자와 구분선이 진해지고 보호막 목표 대비가 7:1로 올라가요.
  • 이미지 배경은 장식이라 보조 기술에서는 숨겨요.
데이터와 개인정보

이미지는 이 Mac 밖으로 나가지 않아요

이미지 배경

  • 고른 이미지는 앱 데이터 폴더(Application Support의 Changmun 폴더) 안에 줄여서 복사해 두고 그 복사본만 써요. 원본 경로는 저장하지 않아요.
  • 동기화, 업로드, 분석이 없고 네트워크 요청도 없어요.
  • 삭제하거나 다른 이미지를 고르면 이전 복사본을 지워요. “기본값으로 되돌리기”는 실행 취소 시간이 지난 뒤에 지워요.
  • 이미지의 위치 정보(EXIF)는 복사본에 담지 않아요.

내가 정한 주소

  • 새 탭을 열 때마다 그 사이트에 요청이 나가요. 사이트는 접속한 시각과 내 IP를 알게 돼요. 그래서 한 줄 안내를 늘 보여 줘요.
  • http 주소는 암호화되지 않으니 노란 안내를 붙여요.
  • 탭이 없는 창은 이 주소를 부르지 않아요.
  • 주소 자체는 환경설정 파일에만 저장해요.
구현 비용

무엇이 싸고 무엇이 비싼가요

쌈

  • 설정 모델: 스타일, 스타일별 {순서, 켜짐, 옵션}, 배경 enum, 새 탭 enum. Codable 한 덩어리.
  • 단색·기본·없음 배경, 스타일 전환, 토글, 옵션, 되돌리기.
  • 새 탭 열기 분기와 주소 검증(URL 파싱, https 보충).
  • 설정 페이지(Form 기반, 기존 설정 페이지와 같은 틀).
  • 구성 요소의 켜기·끄기와 적응형 숨김(지난 시안에서 이미 필요했던 것).

중간

  • 팝오버(알약 앵커, 스크롤, 아코디언 옵션, 고정 바닥글).
  • 스타일 썸네일: 실제 뷰를 축소해 그리기. 3개를 상시 그리면 부담이라 팝오버가 열릴 때만 그려요.
  • 이미지 배경: 파일 선택, 줄여서 복사, 흐림(레이어 블러), 유리 판(Material).
  • 끌어서 순서 바꾸기 + 키보드(⌥↑/⌥↓) + VoiceOver 동작. 기본 List.onMove로 시작하고 뒤 페이지 실시간 재배치는 나중에 더해도 돼요.
  • 반쪽 너비 구성 요소의 짝짓기 규칙.

비쌈

  • 자동 보호막: 밝기와 복잡도 계산, 모드별 재계산, 대비 보장, 경고 문구. 먼저 고정 농도 + 유리 판으로 내고 나중에 자동으로 올려도 돼요.
  • 배경 이미지의 정확한 영역 지정(자르기·위치 조정)은 이번에 뺐어요.
  • 라이트/다크 이미지를 따로 받기(질문 2).
  • 시안의 “놓기 전 미리 보기”는 놓을 자리와 실시간 재배치의 합이라, 첫 버전은 놓을 자리만 보여 줘도 돼요.
고르실 것

열린 질문 5가지

  1. 구성 요소 설정을 스타일마다 따로 기억할까요?이 시안은 따로 기억해요(조용히로 바꿨을 때 대시보드의 구성이 따라오지 않도록). 대신 “대시보드에서 끈 읽기 목록이 AI 먼저에서는 켜져 있다” 같은 혼란이 있을 수 있어요. 하나를 공유하면 단순하지만 스타일을 바꿀 때마다 직접 다시 켜고 꺼야 해요.
  2. 배경 이미지는 한 장일까요, 라이트/다크 두 장일까요?시안은 한 장 + 자동 보호막이에요. 두 장을 받으면 둘 다 가장 예쁘게 나오지만 선택이 한 번 더 늘어요. 처음엔 한 장으로 내고, 보호막이 자주 50%를 넘는다면 두 장 선택을 더할 수 있어요.
  3. 주소 지정일 때 개인 창은?시안은 개인 창 안내 화면을 유지해요. 대안은 (a) 지정한 주소를 개인 창에서도 여는 것(기록은 안 남지만 사이트에는 접속) (b) 개인 창만 시작 페이지 안내. 추천은 지금처럼 안내 화면 유지예요.
  4. 진입점은 알약과 설정만으로 충분할까요?더 둘 수 있는 곳은 시작 페이지 빈 곳 우클릭(“맞춤 설정…”)과 보기 메뉴(“시작 페이지 맞춤 설정…”)예요. 메뉴가 있으면 알약을 못 찾는 사람도 도움을 받지만 메뉴 항목이 하나 늘어요.
  5. 이미지 자르기 UI는 이번에 뺄까요?시안은 가운데 기준으로 가득 채우기(cover)만 해요. 세로 사진이나 아주 넓은 이미지는 중요한 부분이 잘릴 수 있어서, 나중에 “위치 조정”(드래그로 이동)을 더하는 걸 제안해요.

목업의 한계: 데이터(사이트, 제목, 시각)는 가짜이고 배경 이미지 세 장(새벽 능선, 오로라, 색종이)은 이 시안을 위해 직접 그린 추상 그림이에요(제3자 사진 없음). 설정 화면은 앱 설정 창의 구성(사이드바 + 그룹 폼)을 본떠 HTML로 그렸고, 팝오버와 시작 페이지는 지난 시안과 같은 방식으로 실제 앱 창 위에 올렸어요.

앱 코드는 바꾸지 않았어요. 모든 값(보호막 농도, 최대 크기, 줄 수 등)은 제안이에요.
